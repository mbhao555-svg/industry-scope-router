# 报告模板（行业版 / 产业链版）

**使用说明**
- 把 `[方括号]` 换成实际内容；**不适用的条目删除而不是留空**，并在附录 B 说明原因。
- 带 ⚠️ 的字段是**硬要求**，缺一项视为报告未完成。
- **先按 SKILL.md 第 2 节判定类型**，再选对应模板。**混合报告**须加附录 D 的两层关系声明。
- **判据一律以 `references/` 下的文件为唯一权威**（阶段判定见 `阶段判定与投资含义.md`；产业链见 `产业链与出清机制.md`；来源核验见 `来源核验与证据台账.md`）。**本模板只规定"填什么"，不重复阈值与判据**——改规则只改那一个文件。
- ⚠️ **本模板中的旧节号映射**：旧模板的"2.2 发展阶段与周期位置"在本技能里拆到**行业版第三节**与**产业链版第四节/第五节**，判据内容不变，见下方对照。

**触发条件**：行业有**明显地理集聚**时必加；**无集聚时写明"本行业无显著地理集聚"并跳过**，不要留空节。

| 区域 | 核心区 | 规模指标（**口径逐格标注**） | 主导品类 | 国家级头衔 | 升级方向 | 代表企业 | 依据 |
|---|---|---|---|---|---|---|---|

**四条填写纪律**
1. **规模列口径必须统一**（或逐格标注）——混用口径等于没有这一列
2. **"国家级头衔"单列**——国家现代农业产业园／优势特色产业集群／骨干冷链物流基地等是**政策资源**
3. **"升级方向"是关键列**——比"它有多大"更有判断价值
4. **表下写 2–3 条横向结论**——只给表不给结论等于把分析推给读者

**行业级区域分布要多答一个问题**：**行业的地理集中度是否本身就是壁垒**？

# 三、两个模板都适用的通用纪律

## 3.1 交稿前必查（四项）

| # | 检查 | 不通过则 |
|---|---|---|
| 1 | **类型明确吗**（行业／产业链／混合）？ | 回到 SKILL.md 第 2 节重判 |
| 2 | 若是**混合报告**，附录 D **声明段在吗**？ | 补上 |
| 3 | 有无**把行业数据用到环节结论**上？有无**把渗透率用到环节**上？ | 删掉该依据，或补环节级证据 |
| 4 | **八个禁词扫描**（改造／本版／原报告／表格化／★／前版／旧版／上版）是否全为 0？ | 逐个清零 |

## 3.2 排版纪律

| # | 规则 |
|---|---|
| 1 | **单行不超 150 字符**；长段落按句末标点断行 |
| 2 | **带编号的并列结论（①②③）各占独立一行**——不得挤在同一自然段 |
| 3 | **标题行只放标题**；不得写成 `### 1. 结论名 ｜ 正文…` |
| 4 | **表格单元格内最多 2 个数据点**；**单元格 >100 字符须拆到表下** |
| 5 | ⚠️ **判超宽看单元格，不看源文件行**——`| a | b | c |` 在源文件里可能 200+ 字符，但渲染后每格是独立窄列 |
| 6 | **引用块不得超 150 字符**，**不超 5 行连续**，每个要点独立成行 |
| 7 | **元信息块必须表格化**（类型／依据／先决核查） |
| 8 | **能用表格表达的一律用表格**；但**因果连续推演与概念解释仍用散文**——不要为用表把推理压碎 |
| 9 | **禁止 `<br>`** 等 HTML 标签（渲染器会显示成文字） |
| 10 | **不用 Mermaid**（多数渲染器不渲染）——结构图用纯文本树/箭头 |

| 3 | `（按 2.3.1 判据：…）`／`（见第 X 节）` | 删掉——读者不需要规则编号 |
