# 行业 与 产业 的区分（定义与使用规则）

> **本文件是"行业／产业"概念的唯一权威定义。** 任何报告、任何技能引用这两个词时，以本文件为准。

---

## 一、一句话定义

**行业与产业不是包含关系，而是同一经济活动的两种切法——两条轴正交。**

| | **行业** | **产业** |
|---|---|---|
| **按什么切** | **统计分类口径** | **价值流转** |
| **边界由谁定** | 官方分类标准（如《国民经济行业分类》GB/T 4754） | 分析者按上下游关系划定 |
| **有无官方代码** | **有**（如 C1393、C1452、C1523） | **无**——产业是分析概念，不是统计单位 |
| **数据从哪来** | 官方与机构**汇总统计**（规上营收、企业数、产量） | 必须**自己按环节拆**（分部财务、逐环节调研） |
| **回答什么问题** | 这个行业**多大、多少家、增速多少** | 这条链上**钱在哪一段、谁有定价权** |
| **典型判断** | 行业阶段（导入/成长/成熟/衰退） | 环节可投性（进入、规避、绕开） |

---

## 二、为什么不是包含关系（关键纠正）

**常见错误**：试图论证"行业 ⊃ 产业"或"产业 ⊃ 行业"。**两者都不成立**，因为它们量的不是同一个东西。

**正交的实证**（本工作区实测）：

| 事实 | 说明 |
|---|---|
| **预制菜在《国民经济行业分类》中无对应条目**（广东省统计局 2023-03-19 答复） | **有产业，无行业代码**——若为包含关系，产业存在则行业必然存在，事实相反 |
| **果蔬加工横跨 C1393／C1452／C1523 三个行业代码** | **一个产业对应多个行业** |
| 同一家公司（如国投中鲁） | **既是 C1393 下的一个统计单位，也是浓缩苹果汁产业的一个环节点**——两个身份同时成立，互不替代 |

> **几何类比**：一家企业像一个点，行业与产业是穿过它的两条不同的坐标轴。**问"哪条轴包含另一条"是没有意义的。**

## 三、实际是三层，不是两层

| 层级 | 定义 | 例子 | 用途 |
|---|---|---|---|
| **产品／品类** | 消费者可识别的具体形态 | 智能音箱、NFC 果汁、预制菜狮子头 | 读报告、看趋势 |
| **行业** | **统计分类代码**下的单位集合 | 音响设备制造（C39xx）、果汁及蔬菜汁饮料制造（**C1523**） | **拿汇总数据** |
| **产业** | **价值链**：上游→中游→下游 | 智能音箱产业（芯片/声学器件/整机/内容服务） | **判可投性** |

**三者关系**：

```
      产品 ── 属于 ──▶ 一个或多个 行业代码   （拿统计数据的入口）
        │
        └── 位于 ──▶ 某个 产业 的某个环节     （判投资价值的入口）
```

**"品类 ≠ 行业 ≠ 产业"**——把三者混为一谈，就会出现"用某个产品的销量下滑推断整个行业衰退"这类错误。

## 四、三个必须遵守的规则

### 规则 1：**行业级数据不得直接用偏环节**（共线的一种）

| 错误做法 | 后果 |
|---|---|
| 用行业总增速代表某环节增速 | 环节增速与行业增速常不同（如行业 +21% 而中游毛利率两年 −2.7pct） |
| 用行业总企业数推断某环节集中度 | 行业企业数含全部环节，与单一环节无关 |
| 用行业总毛利率代表某环节毛利率 | 混合值——企业常跨环节 |

**正确做法**：**环节结论必须有环节级证据**（该环节的分部毛利率、该环节的企业数）。行业数据只能作为**背景**，不能作为**环节结论的依据**。

### 规则 2：**渗透率是行业级概念，不得跨层套用到环节**

**理由**：渗透率的分母是一个**行业或品类的总量**（如预制菜在餐饮/家庭用餐中的占比）。**单个环节没有"渗透率"**——上游调味品的渗透率相对什么？

| 层面 | 是否适用渗透率硬规则 | 判法 |
|---|---|---|
| **行业** | ✅ 适用 | 五指标投票 + 渗透率校准 → **一个标签** |
| **产业（链）** | ❌ **不适用** | **逐环节**用出清机制定档 → **每环节自己的档位**；阶段标签若给，须**另找该环节自身的驱动/周期信号** |

### 规则 3：**两层标签不同时，必须显式声明为什么不矛盾**

当报告同时给出"行业阶段"与"环节档位/标签"时，**两者可以不同，且不矛盾**——因为量的不是同一个东西。**但必须写清楚**，否则读者无法判断报告是否自相矛盾。

**范例写法**：

> **关于两个层面判断的关系**：本报告给出**行业级**阶段判定（基于全行业增速、企业数量、政策口径）与**环节级**可投性判定（基于各环节分部分部毛利率与出清机制）。两者**不矛盾，也不可互相推导**——行业阶段回答"这个行业整体在什么周期位置"，环节档位回答"这条链上哪一段能投"。**行业判定用行业级数据，环节判定只用环节级数据；渗透率校准仅适用于行业层，未跨层套用。**

## 五、判断流程（先定位层面，再选数据）

```
① 用户给的是一个【行业名】还是【一份报告／一条产业链】？
      行业名    → 走行业层：查分类代码 → 取汇总数据 → 五指标 + 渗透率 → 一个阶段标签
      报告/链   → 走产业层：拆上游/中游/下游 → 逐环节取分部数据 → 出清五问 → 逐环节档位
② 若两者都要（投资分析通常都要）：
      行业层给"阶段与周期位置"，产业层给"逐环节可投性"，并显式声明两层关系（规则 3）
③ 每次下结论前自检：
      - 这条结论用的是行业级还是环节级数据？
      - 若结论是关于某环节的，证据是环节级的吗？（规则 1）
      - 我是否把渗透率用到了环节上？（规则 2）
```

## 六、术语使用纪律（写报告时）

| 什么时候用"行业" | 什么时候用"产业" |
|---|---|
| 提到**分类代码、规上营收、企业数量、官方统计** | 提到**上游/中游/下游、环节、价值链、利润分布** |
| 提到**行业阶段**（导入/成长/成熟/衰退） | 提到**环节可投性**（进入/规避/绕开） |
| 引用**政策文件对行业的口径** | 描述**价值流转与定价权** |

**禁写**：

| 禁写 | 改为 |
|---|---|
| "行业产业链"（同义反复，且层面混乱） | 依语境写"**行业**"或"**产业链**" |
| "某某行业的上游环节"（把行业当链） | "某某**产业**的上游环节" |
| "产业增速"（产业无官方增速） | "**行业**增速"或"该**环节**增速" |

## 七、本定义如何处置既有的三处问题

| 问题 | 现状 | 按本定义处置 |
|---|---|---|
| `industry-lifecycle-analyzer` 的"行业横跨多个产业" vs "产业包含多个行业"**自相矛盾** | 两句话并存 | **两句都删**，改为引用本定义（两轴正交，不问包含） |
| `deep-research`／`report-structure` **都未定义** | 无定义 | 引用本定义；并在判断流程中显式区分两层 |
| 报告里**环节贴"成熟期"却不说明为何不受行业渗透率约束** | 事实存在，未说明 | **补规则 3 的声明段**；环节标签须另找该环节自身信号，或只给档位不给阶段标签 |
