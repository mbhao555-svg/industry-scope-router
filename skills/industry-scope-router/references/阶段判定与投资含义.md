# 阶段判定与投资含义映射

配套 `SKILL.md` 第二步、第五步与 `assets/report-template.md` 第 2.2 节使用。

> **本文件的定位**：它回答两件事——
> 1. **行业处于什么阶段**（第一部分：适配 → 投票 → 校准，三步法定阶段）
> 2. **这个阶段能不能投、按什么逻辑投**（第二部分：阶段 × 出清机制 → 投资含义）
>
> ⚠️ **两件事必须都做。只给阶段标签不给投资含义，等于没做本模块**（本 skill 目的是投资）。反过来，**没有阶段判断的投资结论是空谈**——"低毛利不能投"这类判断缺少最关键的一环。

# 第一部分：怎么定阶段

## 一、前置检查：框架适配性与驱动力识别

**为什么必须先做**：阶段判断隐含一个假设——**行业按市场规模与竞争结构渐进演进**。这个假设对实物商品成立，对相当多行业不成立。不先检查就套指标，会产出"看起来精确、实则不适用"的结论。

### 1.1 驱动力识别：阶段由什么推动？

先回答一句：**这个行业的阶段，主要由什么力量决定？**

| 驱动力 | 识别特征 | 对本框架的影响 | 典型行业 |
|---|---|---|---|
| **市场驱动** | 自由进入、价格由供需定、企业自主进出 | ✅ **框架完整适用** | 消费品、零售、餐饮、家电 |
| **政策 / 牌照驱动** | 准入需许可、价格受管制、经营范围被限定 | ⚠️ **阶段可能一次性跳变**，不遵循渐进演进 | 教育、房地产、金融、医疗、能源 |
| **技术路线驱动** | 主流技术未收敛、标准仍在竞争、代际切换频繁 | ⚠️ **"竞争者数量"失效**（玩家可能还没出现；换代可能重排格局） | 前沿科技、新材料、AI、光模块 |
| **双边网络驱动** | 平台连接两侧用户、存在交叉网络效应 | ⚠️ **渗透率须拆两侧**；规模本身即壁垒 | 平台经济、中介撮合、支付 |
| **资本 / 金融周期驱动** | 高杠杆、依赖融资、资产价格主导 | ⚠️ **"衰退"可能被人为中止或延后** | 房地产、创投、部分重资产 |
| **外部冲击驱动** | 需求受突发公共事件、地缘、气候影响 | ⚠️ **单年数据不可用于判断趋势** | 旅游、航空、会展、农业 |
| **资源周期驱动** | 价格由全球大宗商品周期决定 | ⚠️ **阶段由价格周期而非渗透决定** | 矿业、能源、化工原料 |
| **特许 / 刚性需求驱动** | 牌照垄断 + 需求刚性、不随成熟消失 | ❌ **生命周期不适用** | 烟草、博彩、部分公用事业 |
| **预算 / 采购驱动** | 单一或少数买方，需求由财政预算与招标节奏决定 | ❌ **无渗透率**；阶段由预算周期决定 | 军工、航天、政府采购、公共安全 |
| **自建自用驱动** | 需求由企业内部自供，无外部市场 | ❌ **无市场、无渗透率** | 自备电厂、企业自建数据中心、自研工具 |
| **组织 / 机构采购驱动** | 买方为机构而非个人，购买与使用分离 | ⚠️ **有"机构覆盖率"，无人群渗透率** | 团购礼品、企业福利、机构装备 |

**识别方法（问三句）**：

1. 这个行业能自由进入吗？（不能 → 政策/牌照）
2. 主流技术路线定了吗？（没定 → 技术路线）
3. 需求会随行业成熟而消失吗？（不会 → 刚性需求，生命周期不适用）

**驱动力可叠加**：真实行业常同时具备 2–3 项（如光模块 = 市场 + 技术路线 + 政策/地缘）。**叠加时按最强约束确定适配等级。**

### 1.2 适配性分级：能判到什么程度？

识别驱动力后，确定本次判断的**结论强度上限**。**不得超出适配等级给出更强结论。**

| 等级 | 适用条件 | 允许输出的结论 |
|---|---|---|
| **A 级：完整判断** | 市场驱动；指标齐全；口径可锁定 | 明确的阶段结论 + 置信度 |
| **B 级：有条件判断** | 存在 1 项非市场驱动，但市场因素仍占主导 | 阶段结论 + **显式标注驱动力限制** |
| **C 级：分赛道判断** | 多赛道驱动力不同，或产业内部政策待遇不同 | **只给各赛道分别的阶段**，不给整体结论 |
| **D 级：不适用判断** | 主导驱动为禁止性政策、特许垄断、或刚性需求 | **不给阶段结论**；改为输出"驱动力分析 + 政策状态 + 关键变量" |
| **E 级：数据不足** | 五指标中两个以上缺失 | 输出"数据不足，无法判断" + 缺口清单 |

**判定顺序**：先看数据是否够（否则 E）→ 再看驱动力是否允许判断（否则 D）→ 再看是否需要分赛道（否则 C）→ 最后看是否需标注限制（否则 B / A）。

**若判为 D 级或 E 级，不进入投票与校准，直接跳到第二部分的三（**D/E 级的投资含义另述**）**。

**D 级不给阶段，给什么**：

1. **驱动力说明**：本行业阶段由 XX 力量决定，不遵循市场驱动的渐进演进
2. **政策 / 制度状态**：现行准入、定价、经营范围的具体规定及其出处
3. **关键变量**：哪一两个政策或制度变量决定行业走向，及其可能的变化方向
4. **明确声明**：生命周期框架不适用于本行业，以下为驱动力分析而非阶段判断

**混合驱动是常态**：一个产业内不同赛道可能由不同力量驱动（如教育培训：学科类政策驱动、职教需求驱动、教育硬件技术驱动）。**此时必须分赛道标注各自的驱动力，不得给统一的阶段结论。**

## 二、五指标投票

**执行纪律**：

- 数据优先取**最近 1–2 年**，标注具体年份/季度
- 每个指标**至少尝试 2–3 条不同措辞的检索**，再决定是"有数据"还是"数据缺失"
- 引用的数字要带口径（全国/全球、销量/销售额、规模以上/全部企业），**口径不明时降置信度**
- 搜不到近两年数据 → 写"数据缺失"，**不用三年前的数据替代**
- ⚠️ **投标前必须先过"指标共线检查"**（见本文件第五部分）——共线的两个指标只算一票

| 指标 | 观察结果 → 阶段 |
|---|---|
| **一、增长率** | 增速 **> 20%**（销量与营收同步高增）→ 成长期；**0–10%** 且波动小 → 成熟期；**为负，连续 2 年以上下滑** → 衰退期；增速低但**波动大、口径混乱、无稳定统计** → 导入期；从 >20% 回落到 10–20% → 成长期向成熟期过渡 |
| **二、竞争者数量** | 企业数**快速增加**、新进入者多 → 成长期；**见顶回落**、集中度提高、并购增多 → 成熟期；**大量退出**、注销数持续高于注册数 → 衰退期；竞争者少但**陆续进入、无稳定排名** → 导入期；**企业数多、不减少、集中度不提升，但增速已落入 0–10%** → **成熟期（碎片化陷阱）** |
| **三、进入壁垒** | 门槛低、无强制资质 → 导入期；壁垒中等、标准与资质开始形成 → 成长期；壁垒高（规模经济/品牌/渠道/专利/牌照齐备）→ 成熟期；壁垒高但市场萎缩、牌照价值下降 → 衰退期 |
| **四、产品标准化** | 差异大、无统一标准 → 导入期；标准开始形成（团标/行标/国标立项或刚实施）→ 成长期；高度标准化、同质化、比价为主 → 成熟期；标准化但需求下降 → 衰退期 |
| **五、利润率** | 低或普遍亏损且无稳定统计 → 导入期；高（显著高于制造业平均）且竞争加剧后下滑 → 成长期；稳定但仅平均水平 → 成熟期；低或亏损且需求萎缩、产能过剩 → 衰退期 |

**加细分判据**：

- 增速 10–20% 且竞争者仍在增加 → 成长期后段
- 增速 0–10% 且集中度提高 → 成熟期中后段
- 增速负但价格稳定、只是量减 → 衰退早期；增速负且价格战 → 衰退中后期
- **量价背离**：销量增速明显高于营收增速 → 价格战信号，偏成长期后段/成熟期前段

### 2.1 三个易错点（必须执行）

**① 标准类事件先分清性质**——否则会把成熟期误读成成长期：

| 标准性质 | 含义 | 读法 |
|---|---|---|
| **品类定义标准** | 为新品类建立定义、允许其存在 | **成长期**（品类刚被承认，新玩家会涌入） |
| **运营服务标准** | 既有品类的服务规范、资质要求、编码规则 | **成熟期**（是规范化，不是品类诞生） |

**判定方法**：问"这个标准发布**之前**，该品类是否已经存在并规模化？"——之前**不存在** → 品类定义标准；之前**已存在** → 运营服务标准。

**② 利润率的方向只能靠增速区分**：

- **利润低 + 高增速 + 玩家增多** → 导入期或成长期早期价格战
- **利润低 + 增速低/负 + 玩家退出** → 衰退期
- **利润率高 + 增速仍高** → 成长期（黄金窗口）
- **利润率高 + 增速低 + 集中度高** → 成熟期（寡头稳定盈利）

**同样的"低利润"，含义相反。**

**③ 产品标准化对服务业判别力弱**：服务流程天然可比（"扫码+计时计费"），几乎必然读出"高度标准化"。**在服务型行业，本指标只能作辅助，不得单独决定阶段**，须以增长率与渗透率为准。

### 2.2 非实物行业的指标替换

上表以实物商品为原型。以下业态须**替换对应指标**后再判：

| 业态 | 替换/补充指标 |
|---|---|
| 服务 / 教育 / 医疗 | 续费率、客单价、人效、满班率或床位使用率、退费率 |
| SaaS / 订阅 | 续费率（GRR/NRR）、CAC、LTV、流失率、ARPU |
| 平台 / 双边市场 | 两侧用户数及比例、GMV、take rate、网络密度、**单侧留存（两侧分开看）** |
| 项目制 / 工程 | 在手订单、订单转化周期、应收账款周转、履约进度确认 |
| 零售 / 连锁 | **同店增速（非单店）**、坪效、库存周转、闭店率 |
| 金融 / 高杠杆 | 不良率、资本充足率、拨备覆盖率、净息差 |
| 重资产 / 基建 | 产能利用率、折旧占营收比、资本开支/营收比 |
| 资源 / 大宗 | 价格周期位置、库存周期、边际成本曲线位置 |

> ⚠️ **替代指标不得编造固定阈值**（如"续费率 60% 以上算成熟期"）——**阈值因行业而异，编出来就是伪精确**。正确做法是**两步映射**：①先把它映射回它替代的是哪个原始指标（增长率/竞争者/壁垒/标准化/利润）；②再用"**相对水平**（相对盈亏平衡点或历史常态是高/持平/低）**+ 趋势方向**（升/平/降）"定阶段内**位置**。行业基准取不到时，退而用**头部企业**或**该行业 3 年前的自身值**作参照；都取不到时**只报趋势方向，不报水平判断**。

### 2.3 置信度规则

| 等级 | 条件 |
|---|---|
| **高** | 一手权威数据（财报/统计局/协会/权威咨询）覆盖近 1–2 年，且与其他来源交叉一致 |
| **中** | 二手来源（券商/财经媒体/电商数据），或口径不完全可比，或只有单一来源 |
| **低** | 仅有间接证据、专家观点、口径不明，或数据年份偏旧 |

**整体置信度**：五指标中 **4 个以上为高 → 整体高**；**2–3 个为高或中 → 整体中**；**多数为低 → 整体低**。**取不出"高"时必须显式降级并说明原因。**

### 2.4 投票后的量化判读（避免"只贴标签"）

**给出"高/中/低"这类定性判断后，须把关键指标的量化读数列出**，否则结论无法复核。至少覆盖：

| 读法 | 说明 |
|---|---|
| **增速分档** | 落在哪一档（>20% / 10–20% / 0–10% / 负），以及**最近 2 年的方向**（加速/持平/减速） |
| **集中度** | CR4 或 CR8 的**当前值与两年变化**——CR4 两年内提升 ≥10 个百分点 = 成长期向成熟期过渡的强信号 |
| **量价关系** | 销量增速 vs 营收增速的**差值**（差值为负且扩大 = 价格战加深） |
| **亏损面** | 亏损企业占比及其变化方向 |
| **产能利用率** | 当前值（<75% 过剩 / >85% 偏紧） |

⚠️ **数值取不到时写"数据缺失"，不得用定性词汇替代**。

## 三、渗透率校准（不投票，只设上界）

> **前置提醒**：本节规则是"**任何比值型指标都要先问分母**"这一原则的特例。渗透率是分母问题最集中的指标。

### 3.1 前置检查：本行业有渗透率这个概念吗？

**渗透率默认行业面向最终消费者。** 先按顺序问两句：① **购买决策单位是否颗粒化？**（个人/家庭 vs 少数机构）② **购买者是否即最终受益者？**

| 需求侧形态 | 适用性 | 处置 |
|---|---|---|
| 最终消费品 | ✅ 适用 | 直接计算 |
| 渠道 / 服务网络 | ✅ 适用 | 用门店覆盖率、连锁化率 |
| 广告 / 内容 / 媒体 | ✅ 适用 | 受众渗透率、人均使用时长 |
| **双边平台** | ⚠️ **分买卖两侧** | 两侧分别算，**禁止合并**；另报 take rate 与撮合成功率 |
| **机构 / 组织采购** | ⚠️ 换分母 | 分母是**机构数**而非人口数 |
| **中间品 / 元器件** | ❌ 跳过 | 改用下游资本开支增速、下游产量增速 |
| **B 端设备 / 工业品** | ❌ 跳过 | 改用下游产能扩张速度、设备更新周期 |
| **政府 / 公共采购** | ❌ 跳过 | 改用财政预算增速与分配占比、中标金额 |
| **自建自用** | ❌ 跳过 | 无市场，改判企业内部替代进度 |

**若判定不适用**：① **整步跳过校准**，写明"本行业为 XX 形态，无自身渗透率，未做校准"；② 按上表改用替代指标；③ 中间品 / B 端须写明**传导关系**（"下游每提升 1 单位产能，需 X 单位本产品"）。

**区分四种情况**（处置不同）：无需求侧渗透 → **整步跳过**；面向消费者但数据缺失 → 不校准，写明原因；**有多口径** → 锁主口径、其余并列；双边平台 → 分侧计算。

### 3.2 它设定上界，不投第六票

- **渗透率低 → 无论五指标怎么投，都不能判成熟期或衰退期**
- **渗透率高 → 不能判导入期**

原因：渗透率衡量"还有多少人没用上"，即**剩余空间**。只覆盖 10% 人群的品类在逻辑上不可能是成熟期，哪怕增速、集中度、利润率暂时都像成熟期（那通常是导入期末的**成熟期假象**：样本小、统计口径不稳定、早期玩家少导致集中度虚高）。

### 3.3 阈值表

| 渗透率 | S 曲线位置 | 校准作用 |
|---|---|---|
| **< 5%** | 导入期 | 上界封在**成长期**，不得判成熟期/衰退期 |
| **5%–15%** | 导入期末 / 成长期最早期 | 上界封在**成长期** |
| **15%–20%** | **临界点**（越过即进入快速提升期） | 上界封在**成长期**（未越线时不得判成熟期） |
| **20%–35%** | 成长期（快速渗透段） | 不设硬上界；提示成熟期需强证据 |
| **35%–40%** | **临界点**（越过即增速开始放缓） | 提示进入成长期后段 |
| **40%–60%** | 成长期后段 → 成熟期 | 允许判成熟期 |
| **> 60%** | 成熟期（存量博弈）**← 须做深度校验** | **下界抬到成熟期**，不得判导入期 |

**两个临界点（15%–20%、35%–40%）是 S 曲线拐点区间。** 数值落在临界区间时**必须显式写"处于临界点"**并给出越过/未越过的依据，**不得二选一**。

### 3.4 两条硬规则（不可绕过）

| 硬规则 | 执行方式 |
|---|---|
| **渗透率 < 20% → 不得判成熟期或衰退期** | 若五指标投出成熟期/衰退期，**改写为"成长期"**（或导入期，视五指标而定），并在综合判断里写明冲突点 |
| **渗透率 > 60% → 不得判导入期** | 若五指标投出导入期，**改写为"成熟期"**，同样写明冲突点。⚠️ 实践中几乎不出现，出现时**优先怀疑口径错误** |

**冲突点必须写清三件事**：① 五指标投出什么阶段、依据哪几条证据 ② 渗透率读数、属哪一档、触发哪条硬规则 ③ 修正后结论与理由。**不得隐去冲突、不得只给修正后的结论。**

### 3.5 深度校验：渗透率 > 60% 时必做

**渗透率只衡量"广度"（有多少人在用），不衡量"深度"（每人花多少）。** 广度饱和后，只看渗透率会把两种截然不同的行业判成同一阶段：

| | 广度（渗透率） | 深度（单位消费强度） | 真实状态 |
|---|---|---|---|
| 宠物零食 | 85.2% | 约 209 元/只/年——**浅** | 用户数到顶，但每只有很大加码空间 |
| 速冻食品 | 高度普及 | 客单稳定、增速仅 2.2% | 广度与深度双双见顶 |

**两者都判"成熟期"，但决策含义完全相反**：前者投高端化与功能化，后者防守份额。

**单位消费强度取法**：消费品→单宠/单人年均消费额、人均年消费量；零售→同店营收、店均坪效；SaaS→ARPU；制造业→单位客户采购额；公用事业→人均用量。

**校验后的结论**：

| 广度 | 深度 | 阶段结论 |
|---|---|---|
| < 60% | 任一 | 按阈值表判断，**无需深度校验** |
| > 60% | **低且仍在提升** | **成长期后段 → 成熟期前段（增长引擎切换中）** |
| > 60% | 高且已稳定 / 见顶 | **成熟期（存量博弈）** |
| > 60% | 低且**在下降** | 成熟期偏后段，**须排查是否为衰退前兆** |

**"低且仍在提升"如何判定**：有同比数据 → 单位消费强度同比正增长；无同比数据 → 对比人均可支配收入增速、或与成熟市场的差距倍数；**两者都取不到 → 写明"未做深度校验"，按渗透率档位保守取值（即成熟期），并说明可能存在低估**。

**深度指标自身有两个口径**（取错会让"引擎切换"与"存量博弈"直接反掉）：

| 口径 | 算法 | 含义 |
|---|---|---|
| **A：活跃口径** | 总消费额 ÷ **实际消费的用户数** | 已经消费的人**花多少**（ARPU、客单价） |
| **B：潜在口径** | 总消费额 ÷ **全部潜在用户数** | 平均每个潜在用户**贡献多少** |

**关系**：`口径 B = 口径 A × 渗透率`。**默认用口径 B**（当广度仍在变化时尤其如此），因为`行业增长 = 潜在用户数 × 口径 B`，它是唯一能直接对应营收增长的深度读数。**口径 A 的专用途**：判断存量用户挖掘空间、或行业处于衰退用户流失期。

**两口径冲突时不裁决对错**，合起来读：

| 口径 A | 口径 B | 读法 |
|---|---|---|
| ↑ | ↑ | 深度与广度同向改善，引擎切换顺利 |
| ↑ | ↑（更快） | 广度仍贡献增量，深度亦提升（双引擎） |
| → / ↓ | ↑ | **广度仍扩，但老用户消费停滞**——增量全靠拉新 |
| ↑ | → / ↓ | **深度在提，但用户数在流失**——排查衰退前兆 |
| ↓ | ↓ | 深度见顶且用户流失，成熟期后段或已衰退 |

**报告必须写明深度指标用的是哪个分母。** 只写"人均消费 209 元"不写分母，读者无法判断它衡量的是活跃用户还是全部潜在用户——**两者相差的正是渗透率本身**。

### 3.6 口径即结论：换分母就是换问题

**这不是"用错口径会得出相反结论"，而是不同口径各自正确、各自回答不同问题。**

同一个产业可以**同时处于两个阶段**——以新能源汽车为例（**数值为示意，须以当次检索为准**）：

| 口径 | 示意数值 | 对应阶段 | 回答的问题 |
|---|---|---|---|
| 保有量 | ~10%–15% | 成长期早期 | **增长还有多大空间**——存量中有多少已替换 |
| 中国新车销量 | >50%–60% | 成熟期早期 | **新增需求是否见顶** |
| 全球销量 | ~20%–25% | 成长期前半段 | 全球渗透进度 |

**"新增市场已进入成熟期，存量市场仍处成长期早期"——这句话内部没有矛盾**，它描述同一产业的两条不同战线。因此：**不要**裁决哪个口径"才对"；**不要**把口径矛盾当数据不可靠的证据；**要**说明每个口径各自指向什么阶段。

**先声明判断问题，再选口径**（口径由**问题**决定，不由数据可得性决定）：

| 判断问题 | 主口径 |
|---|---|
| 增长还有多大空间 / 还能不能进 | **存量 · 保有量** |
| 新增需求是否见顶 | **销量** |
| 全球市场处于什么阶段 | **全球** |
| 出口 / 海外业务天花板 | **出口 / 目标国** |

**主口径与并列结论的分工**：主口径**只用于触发硬规则**（一次校准只能有一个主口径）；**其余口径全部列出并各自给阶段**——它们不是噪声，而是同一产业在不同战线上的真实阶段。**不得混用**（不能用 A 口径的渗透率配 B 口径的增速）。

**口径选择还决定后续跟踪什么**——选错会产生方向性误判：

| 主口径 | 后续应跟踪 | 不该跟踪 |
|---|---|---|
| 保有量 | 保有量渗透率年增幅、存量替换进度 | 新车销量增速（已饱和，会误判为衰退） |
| 销量 | 销量增速、店均/车企均销量 | 保有量占比（滞后） |

**口径不明 → 置信度记低，且不得触发硬规则**，按数据缺失处理。理由：无法确认口径的渗透率不能确定它回答哪个问题，用它封上界会把可能已成熟的产业错判成成长期，**而错误会被"硬规则"的权威性掩盖**。

### 3.7 没有渗透率的行业：替代指标

替代指标**同样只做上界校准，不投票**：

| 行业类型 | 替代指标 | 参考阈值与读法 |
|---|---|---|
| 制造业 / 工业 | 自动化率、机器人密度、**产能利用率** | 产能利用率 <75% ≈ 过剩（成熟/衰退）；>85% ≈ 偏紧（成长/成熟）；自动化率低且上升 ≈ 成长期 |
| 替代进口类 | **国产化率** | <20% ≈ 导入期/成长期早期；20%–50% ≈ 成长期；50%–80% ≈ 成长期后段→成熟期；>80% ≈ 成熟期 |
| 服务业 | 持证机构覆盖率、连锁化率 | 低且上升 ≈ 成长期；高且稳定 ≈ 成熟期；下降 ≈ 衰退期 |
| 农业 / 资源类 | 规模化种养比例、机械化率 | 同国产化率读法 |

**使用边界**：① 替代指标与渗透率**地位相同**（只校准上界）；② **找不到时明确写"本行业不适用渗透率校准"，如实按五指标结果输出，不得因为没有渗透率就拒绝判断**；③ **不得为了凑校准而硬套**——若替代指标与阶段含义不明确（如产能利用率长期稳定 70% 但行业明显在成长），写明不适用，不强行触发规则。

**单轴型 vs 多轴型**（最容易出错处）：问"**这两个指标的决策主体是同一个吗？**"

- **是同一个** → **单轴型**，衡量同一根轴，**可合并读取**（如"国产化率 >50% + 产能利用率 58%"合读为成熟期）
- **不是同一个** → **多轴型**，对应**结构不同的市场**，**不可合并、不可平均、不可互为替代**，必须分轴判断

**多轴型的处理（三步）**：

1. **按渠道分别判断**——每个渠道用自己的代理指标，各自得阶段（B 端看门店覆盖率/连锁客户渗透率；C 端看家庭渗透率/复购频次/人均年消费量）
2. **按权重合成产业整体阶段**——用**收入或销量占比**定主导渠道，**产业整体阶段 = 权重最大渠道的阶段**，并注明"以 XX 渠道为主导"。**不得把两个渠道的阶段做平均**（"B 端成熟 + C 端成长 → 平均为成长期后段"是错的——不存在这样的平均市场）
3. **另一渠道写入结构分化**——明确写清各渠道各自阶段、两条战线共同刻画了什么、**增量在哪条渠道**（这往往比整体标签更有决策价值）

**执行顺序**：**先做多轴分层**（这行业有几个市场？）→ **再在每个市场内定口径**（这个市场用哪个分母？）→ **最后按权重合成**。

### 3.8 渗透率的置信度

| 等级 | 条件 |
|---|---|
| 高 | 权威机构（统计局/协会/头部咨询）给出明确渗透率，口径清晰且与判断目标匹配 |
| 中 | 券商测算或媒体引用；或口径需推断；或多口径并列需自行锁定其一 |
| 低 | 仅有间接推算、口径不明、或只能用替代指标且含义不明确 |

**对整体置信度的影响**：渗透率置信度为高或中 → 参与整体评定并按硬规则校准；**数据缺失 → 不拉低整体置信度**（它不是必备项），但须写明"未做渗透率校准"；**口径不明 → 记低且不得触发硬规则**；**与投票冲突且触发修正 → 整体置信度最高只能给"中"**。

## 四、阶段标签与判断顺序

### 4.1 阶段标签总表（七个）

| 标签 | 定义 | 该观察什么 |
|---|---|---|
| **导入期 / 成长期 / 成熟期 / 衰退期** | 标准四阶段 | 见五指标判断标准 |
| **政策终止** | 被行政命令终结——**需求仍在，但不得满足** | **政策是否重新开放** |
| **技术终止** | 被更优技术整体替代——**需求已单向转移到新技术上，且未见回流** | **是否有替代技术让它复活**；同时观察**需求是否回流** |
| **衰退后回稳** | 经历深度下滑后止跌，稳定在新均衡 | **新均衡能否维持** |

### 4.2 判断顺序（按序执行，命中即停）

```
① 需求是否被行政命令禁止？        → 政策终止（结束，不再往下判）
② 是否被更优技术整体替代？        → 技术终止
   ⚠️ **边界判定（须查两步，缺一不可）**：
   ① 是否**曾**被替代？——看历史（有无长期萎缩期）
   ② 需求**现在是否仍单向转移**？——看近 1–2 年：**若原品类台数与金额双增（需求回流），则不判技术终止**
**实测反例一（数码相机，2026-10）**：智能手机确在 2010 年代替代了低端卡片机，但 2025 年数码相机台数与金额**双增**、便携相机强势反弹 → **需求回流向专用设备，而非单向转移** → **不判技术终止**（该报告正确判为"成熟期（结构性再成长）"，而非按"被替代"一判了之）
   **实测反例二（智能音箱，2026-10）**：该品类连续六年下滑、2026 年 4 月线上 **−50.5%**，表面极像"被替代"。但**蓝牙音箱同期 +3.9%**——**被替代的不是"音箱"，是"带语音助手的音箱"**。**音箱需求仍在，只是"智能"那一层被证伪** → **不判技术终止**，判衰退期
   **⚠️ 由此确立判定要点**：问"是否被替代"时，**先确定被替代的到底是哪个品类边界**。**品类内部某一层（如"智能"）失效，不等于整个品类被技术终止。** 须找出**仍在增长的同品类细分**作为反证
   **若已见小众复兴迹象，须在报告中注明**（本规则原有的要求）
③ 是否仍在下降？                  → 衰退期
④ 是否已止跌且剩余玩家普遍恢复盈利？ → 衰退后回稳
⑤ 其余                          → 按五指标 + 渗透率校准判四阶段
```

> ⚠️ **顺序不可颠倒。** 若颠倒，特殊标签类行业会在五指标上投出"衰退期"（如 K12 学科类：机构数 −96%），再被"以规模增速为终审"确认，**从而把"政策终止"误判成"衰退期"**——而这两个标签的**决策含义相反**（一个看政策是否重开，一个看需求是否见底）。
>
> **三个特殊标签均不得与"衰退期"混用。**
> **"衰退后回稳"须同时满足两条**：量连续 2 年不再下滑 **且** 剩余玩家普遍恢复盈利。**仅降幅收窄不算**，仍判衰退期。

### 4.3 判据冲突裁决顺序

**按序裁决，前一条能解决就不进入下一条。**

| 优先级 | 判据 | 说明 |
|---|---|---|
| **终审** | **规模增速**（增长率指标） | 最直接、最难操纵 |
| **次审** | **渗透率区间** | 设定上界 |
| **仅参考** | **定性判据**（进入壁垒、产品标准化、标准发布等） | **只在缺增速数据时才能作为主要依据** |

**裁决纪律**：定性判据与增速方向相反时，**以增速为准**，并写明冲突。

**凡使用了裁决，必须记录**：① 冲突是什么 ② 适用哪一条 ③ 裁决结果 ④ **若裁决改变方向，写出被否决的一方及其理由**。**未记录裁决过程的报告，视为不合格输出。**

# 第二部分：阶段怎么变成投资结论

> 🔴 **这一部分是本模块与普通行业分析的分水岭。**
>
> **只给阶段标签 = 没有投资结论。** 但反过来，**只看阶段也不能投**——两个行业可以同样判"成熟期"，投资含义完全相反（一个投高端化，一个防守份额；一个该进，一个该躲）。
>
> **决定差异的是"出清机制"**——弱者能否退出、份额能否向头部集中。**所以投资结论 = 阶段 × 出清机制，两者是乘法关系。**

## 五、投标前的指标共线检查

**产业链与生命周期分析中天然存在共线风险**——多个"看起来独立"的维度可能只是同一事实的不同说法。**把共线指标当作独立证据，会系统性高估置信度。**

| 共线组合 | 为什么是同一份信息 | 处理 |
|---|---|---|
| **集中度高 ↔ 进入壁垒高** | 在配额/牌照行业，**高壁垒正是"企业数少"的原因** | 问"低企业数是因为**壁垒挡住新玩家**，还是**市场出清后自然集中**？"前者同源，**不得当作两票** |
| **毛利率高 ↔ 定价权强** | 高毛利可能是周期高点、单笔订单或会计口径造成 | 定价权须由**客户集中度、切换成本、认证周期**独立支撑 |
| **环节毛利率高 ↔ 该环节价值高** | 同一份财报分部数据的两种表述 | 价值判断须另有依据（资本回报率、现金流、再投资需求） |
| **行业增速高 ↔ 该环节增速高** | 若该环节收入占比极高，两者基本是同一个数 | 需给出该环节**独立于行业**的驱动因素 |
| **生命周期阶段 ↔ 产业链结构** | 两者常源自同一批数据、同一批来源 | **不得把"阶段与结构互相印证"当作双重证据**——它们是一次取证的两个侧面 |

**判定方法（两问）**：① **问因果**——A 高是不是 B 高的原因（或反之）？② **问数据源**——是否来自同一份原始数据？

**执行要求**：报告中须注明同源项；**同源项不得用于提高置信度**——若某结论的支撑证据去掉同源项后只剩 1 个，该结论**按"单源"处理，标注待核实**。

## 六、出清机制诊断（五问）

**"出清"指弱者退出、份额向头部集中。有出清机制的行业，低毛利是暂时的；没有的，低毛利是永久的。**

| # | 出清机制 | 判别信号 | 缺它则 |
|---|---|---|---|
| 1 | **并购整合** | 近 3 年是否发生并购？头部是否在收购中小玩家？ | 想整合但整合不了 |
| 2 | **标准与等级** | 消费端是否有被广泛认可的质量/等级标准？国标是否落地执行？ | **整合缺乏抓手**——无法区分优劣，就无法溢价，也无法集中 |
| 3 | **监管门槛抬升** | 准入、合规成本是否在提高（新国标、环保、资质）？ | 新玩家持续涌入 |
| 4 | **渠道集中** | 下游渠道是否在集中（连锁化、平台化）？能否倒逼上游集中？ | 上游永远面对碎片化买方 |
| 5 | **规模经济显著** | 头部单位成本是否显著低于中小玩家（差 ≥10%）？ | 规模不产生优势，大者不能胜小者 |

| 命中数 | 判定 | 结构含义 |
|---|---|---|
| **≥3 条** | **有出清机制** | 低毛利是阶段性的，格局会收敛 |
| **1–2 条** | **出清缓慢** | 需要长周期等待，整合路径不清晰 |
| **0 条** | 🔴 **碎片化陷阱** | **长期低水平均衡**：规模不再增长、格局又无法收敛 |

### 6.1 碎片化陷阱：独立形态（不是成长期，也不是衰退期）

| | 成长期的高低度分散 | **碎片化陷阱** |
|---|---|---|
| 企业数量 | 快速增加 | 多，但**不减少也不快速增加** |
| 集中度 | 低 | 低，且**无提升迹象** |
| **规模增速** | **> 20%** | **已落入 0–10%** |
| 并购整合 | 罕见 | 罕见（**想整合但整合不了**） |
| 成因 | 市场快速扩容 | **缺乏消费端统一标准**，市场无法完成整合 |

**与"衰退期"的决策含义相反，禁止混用**：

| | 衰退期 | 碎片化陷阱 |
|---|---|---|
| 规模 | 持续收缩 | **不再增长但也不大幅萎缩** |
| 企业数 | 持续退出 | **多，但不减少** |
| 集中度 | 提升（弱者死了） | **不动**（弱者死不了） |
| 决策含义 | 观察**需求是否见底** | 观察**出清机制是否出现** |

**实测锚点**：茶叶——企业 163.5 万家、三家上市茶企合计仅占 **1.2%**，而内销总额、总量、均价**同步回调**。成因正如行业分析指出："头部茶企市占率低的根本原因是**市场上缺乏清晰、一致的标准**。"

### 6.2 出清机制按环节拆（不是按行业判）

**同一个行业内，不同环节的出清机制可以完全不同。** 因此五问要**逐环节**做：

| 环节类型 | 常见命中 | 典型判定 |
|---|---|---|
| 品牌 / 品种 / 技术端 | 标准 ✅ 规模经济 ✅ 监管 ⚠️ | **有出清机制** → 可投（剩者为王） |
| 基础设施 / 冷链 / 网络端 | 监管 ✅ 并购 ✅ 规模经济 ✅ | **有出清机制** → 可投（但常是"成本改善"而非定价权） |
| 流通 / 分销 / 零售端 | 标准 ❌ 规模经济 ❌ | **碎片化陷阱** → 🔴 规避 |

> **执行要求**：**不得给行业一个统一的出清判定**——那会掩盖"两端可投、中间不可投"的真实结构。**出清判定必须落到环节**，与分环节强度表并列输出。

## 七、投资含义矩阵（阶段 × 出清机制）

> 🔴 **这是本模块的产出核心。** 填完这张表，才算完成投资判断。

| 阶段 ↓ / 出清 → | **有出清机制**（≥3 条） | **出清缓慢**（1–2 条） | **碎片化陷阱**（0 条） |
|---|---|---|---|
| **导入期** | ⚠️ **极早期**：只投"卖铲人"（设备/材料/工具链），不投终端。**标准化是买入前提** | ⚠️ **同左，但更严**——出清不明时只投有明确付费方的一环 | 🔴 **不投**：技术未定 + 无整合路径 = 双重不确定 |
| **成长期** | ✅ **首选**：投份额领先者（格局收敛中，剩者为王）。**黄金窗口** | ⚠️ **可投但要挑环节**：只投单位成本/周转显著优于同业的（差 ≥10%） | 🔴 **陷阱高发区**——增速高会掩盖"格局永不收敛"。**只投"绕开该环节"的位置** |
| **成熟期** | ✅ **可投**：投整合者与被整合标的。**现金流与份额比增长重要** | ⚠️ **效率游戏**：只投成本领先者，**不投"行业反转"叙事** | 🔴 **最差组合**：低增长 + 无出清 = **长期低水平均衡**。**明确规避** |
| **衰退期** | ⚠️ **尾部出清**：投能活到最后的龙头，**观察需求是否见底**。实测落点：**"剩者为王 + 类债现金流"**——逻辑是**份额提升与分红，而非行业景气反转** | ⚠️ **谨慎**：出清慢意味着痛苦期更长 | 🔴 **不投**：既无增长也无出清 |
| **政策终止** | — | — | — |
| **技术终止** | — | — | — |
| **衰退后回稳** | ✅ **可投**：新均衡已被验证，**投格局与新均衡的维持能力** | ⚠️ 需确认新均衡不是暂时的 | 🔴 不投 |

**三个特殊标签另按驱动力判断，不进本矩阵**：

| 标签 | 判断依据 | 投资含义 |
|---|---|---|
| **政策终止** | 观察**政策是否重新开放**，不是需求是否见底 | 投"政策重开"的期权价值；**不得按衰退期抄底逻辑操作** |
| **技术终止** | 观察**是否有替代技术让它复活** | 一般规避；若存在复活路径，那是技术期权而非行业投资 |
| **衰退后回稳** | 须同时满足"量连续 2 年不下滑"+"剩余玩家普遍恢复盈利" | 可投**格局**（剩者），不可投**成长** |

### 7.1 矩阵使用纪律

1. **先定阶段（第一部分三步法），再定出清（第六部分五问），最后查矩阵**——顺序不可颠倒
2. **阶段与出清都要落到环节**：若某环节的阶段与行业整体不同（如"行业成熟、某细分仍在成长"），**要按环节分别查矩阵**
3. **D 级 / E 级适配不给阶段**，只给驱动力分析；此时矩阵不适用，投资结论须显式声明"因框架不适用，未做阶段×出清判断"
4. **矩阵给出的是"投资逻辑与所需条件"，不是"买入建议"**——标的层判断须另做财报与估值分析

## 八、结构分化：总量会掩盖结构（每份报告必查）

**行业级的总量数字常掩盖相反方向的细分读数。** 实测锚点：**自行车总产量 +11.3%，而中高端运动车 +40%、配套装备 +60%**。

**规则**：凡给出"行业整体低增长/衰退"的判断，**必须同时检查是否存在高增长细分**：

1. 是否有细分品类的增速 **≥ 行业整体的 3 倍**？
2. 该细分的**占比**是多少（占比过小则不足以改变整体判断）？
3. 它是否构成"**第二曲线**"的起点（有独立驱动因素）？

**只写"行业低增长"几乎不提供决策信息**——**存量与增量的读数常反差极大**。若存在显著高增长细分，必须分开陈述，并说明整体判断以哪一端为主导。

**反向核查**：同样要检查是否有"**被整体增长掩盖的萎缩细分**"。

## 九、政策性扰动：负增长不等于衰退（政策刺激类行业必做）

**政策退坡与真实需求萎缩会产生同样的负增长读数，但含义完全相反。**

| 负增长类型 | 判定依据 | 是否算阶段转换 |
|---|---|---|
| **刺激退坡** | 前期有政策驱动脉冲；退坡时点与下滑吻合；幅度与补贴退坡同量级 | **否**（读数失真） |
| **需求透支** | 政策期销量显著高于历史趋势线；退坡后超常下滑；渗透率已近饱和 | **否**（但须提示"透支后有 1–3 年真空期"） |
| **真实萎缩** | 下滑与政策周期**无对应关系**；有可识别替代品；**渗透率仍低却仍在下滑** | **是**（按衰退期处理） |

**执行要求**：政策刺激类行业的增长率**必须做此拆分**，不得直接用名义增速判定；报告中写明"**X% 的负增长中，约 Y% 可归因于政策退坡/透支**"。**不得因政策性负增长而判定衰退期。**

## 十、本模块的边界（必须在报告中声明）

**它回答什么**：阶段定位、阶段内位置、阶段转换信号、后续跟踪变量、结构分化、**以及阶段×出清对应的投资逻辑与所需条件**。

**它不回答什么**（不得用它回答，也不得因答不出而认为它失效）：

| 不回答 | 原因 | 该用什么 |
|---|---|---|
| **拐点时点** | 框架判断阶段，不预测何时转换 | 周期分析、领先指标体系 |
| **政策走向** | 政策是外生变量 | 政策研究；本框架只能标注"阶段由政策主导" |
| **区域具体判断** | 只能分层列出各区域阶段 | 区域尽调 |
| **个量与标的选择** | 阶段与结构是行业级判断 | 公司基本面分析、财报与估值 |
| **景气度高低** | **阶段 ≠ 景气**。衰退期的尾部出清可能伴随龙头景气回升 | 单独的景气度框架 |
| **买入时点与仓位** | 不是本框架的输出 | 投资决策流程 |

> **关键区分（易混）**：**阶段 ≠ 景气**。行业判"衰退期"而龙头景气回升（尾部出清）是常见组合，两者不矛盾。**不得用景气度反推阶段，也不得用阶段替代景气判断。**

## 十一、两套判断的置信度合成

本 skill 的投资结论同时依赖**生命周期判断**与**产业链结构判断**，两者的置信度**不得相加或互相提升**：

| 合成规则 | 说明 |
|---|---|
| **取较低者** | 结论置信度 = min(阶段判断置信度, 结构判断置信度)。⚠️ **必须在报告中显式写出这一行**——实测发现报告常只写单点置信度（"该判断置信度下调"），**未做两者合成**，读者无法判断整体结论上限 |
| **不得互相抵消** | 阶段置信度"高"不能弥补结构数据的缺失，反之亦然 |
| **不得重复计票** | 两者若源自同一批数据，**适用共线规则**（第五部分），只算一份证据 |
| **触发过硬规则修正** | 若渗透率修正过阶段，整体置信度**最高只能给"中"** |
