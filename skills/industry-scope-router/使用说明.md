# 使用说明：行业深度调研报告引擎（industry-deep-research）

## 这是什么

一个 DSH 全局技能（skill）。你把**行业**和**特别关注点**丢给它，它自动按固定口径完成一次行业深度调研，产出一份**每个数字都能追溯来源**的报告。

它解决的问题是：AI 写行业报告最大的毛病有两个——**数据是编的**，**结论是套话**。这个技能用一套硬规则把这两件事堵住：

- 关键数字必须**两个独立来源**印证，单来源一律标"待核实"
- 每个数字后面**必须带来源名称和发布时间**，超过 18 个月要说明参考价值
- 每个核心判断**必须给反面证据**，找不到就写"未找到反方证据"并下调置信度
- 来源冲突时**并列展示，禁止取平均值**
- 查不到的地方写"未披露""待验证"，**不许用看似精确的数字填空**
- 搜"融资/IPO/并购"**连续 4 条查询都没有事件**时，**不许只写一句"未找到融资事件"**——自动降级为**资金结构**分析（政府财政／银行信贷／产业资本／企业自筹／行业基金五类），并翻译成投资含义（现金流有多依赖补贴、有没有产能过剩前兆、退出靠并购还是 IPO）
- 报告末尾必须有**信息缺口清单**：缺什么、影响哪个结论、下次怎么补

## 安装（已为你完成，约 30 秒可自查）

技能已经放在 DSH 用户技能目录（Windows 默认位置；macOS / Linux 为 `~/.dsh/skills/industry-deep-research/`）：

```
%USERPROFILE%\.dsh\skills\industry-deep-research\
```

**不用重启、不用安装命令**，DSH 按文件系统扫描技能目录，新技能会在下一个会话轮次自动出现在可用技能清单里。

**确认装好了**：新开一个对话，问一句

```
industry-deep-research 这个技能是干什么的？
```

如果它能说出"逗号前是行业、逗号后是特别关注点""默认中国+全球对比""默认目的是投资"，就装好了。

> 想装到别的电脑：把整个 `industry-deep-research` 文件夹拷贝到那台机器的 `C:\Users\<用户名>\.dsh\skills\` 下即可。**必须整个文件夹一起拷**——`SKILL.md` 里引用了 `references/` 和 `assets/` 下的 4 个文件，只拷 `SKILL.md` 会导致执行时读不到检索包和模板。

## 怎么用

### 0. 什么说法会自动触发它

以下说法都能直接触发，不用点名（技能靠这段话匹配）：

| 类型 | 说法示例 |
|---|---|
| 带关注点的标准句式 | `预制菜行业，在广西落地出海机会在哪里？` |
| 调研类 | 行业调研、深度调研、行业分析、帮我研究一下 X 行业 |
| 判断类 | 分析一下 X 行业、评估 X 行业、X 行业能不能投、值不值得做、X 行业前景如何 |
| 专题类 | X 行业市场多大 / 竞争格局 / 投融资、X 落地有哪些优势、X 出海机会 |
| **产业链类** | 产业链 / 供应链研究、核心零部件、技术壁垒、利润池、价值捕获、价值分布、价值迁移、国产替代 |

**不会触发的**（按设计不启动本流程）：只要一个数字或一个事实——直接问就行，会直接检索回答，不生成整份报告。

### 0.1 产业链专项模块

关注点涉及产业链、核心零部件、供应链、国产替代、利润池、价值迁移时，会**额外加载产业链专项**（`references/industry-chain.md`），在常规报告基础上多做六件事：

| # | 做什么 | 关键约束 |
|---|---|---|
| 1 | 结构拆解 + **纯文本结构图** | **不用 Mermaid**——DSH 等渲染器不渲染它，用户会看到一堆源码 |
| 2 | 核心零部件分析 | **样机 ≠ 量产 ≠ 客户验证 ≠ 成本竞争力**，四个阶段分开判 |
| 3 | 技术与竞争壁垒 | 三层分开：壁垒高不高 → 能否转化为利润 → 利润能否持续 |
| 4 | 利润池与价值捕获 | 区分**价值创造 / 价值捕获 / 利润可持续性** |
| 5 | 九维价值分布矩阵 | 数据不足用「高/中/低（初步判断）」，**不编造精确评分**；必填"证据可信度"列 |
| 6 | 3–5 年价值迁移 | 三情景 + 触发条件 + 领先指标；**事实与情景推演分开写** |

**先做适用性判断**：平台、纯软件、轻资产服务、金融内容这类**没有物理/工艺链条**的行业，不会硬套"上游→中游→下游"，而会改用替代拆法并写明理由。

### 1. 最简单的用法：一句话

格式是「**行业，特别关注点**」——**逗号前是行业，逗号后是你特别想搞清楚的问题**：

```
预制菜行业，在广西落地出海机会在哪里？
```

```
储能行业，工商业储能能不能跑通盈利模型？
```

```
宠物食品，国产替代的机会在哪里？
```

### 2. 也可以只说行业

```
帮我调研一下预制菜行业
```

这时它会自己补一个默认关注点：该行业的投资机会与主要风险。

### 3. 想更可靠就点名技能

```
用 industry-deep-research 调研预制菜，关注点在广西落地和出海
```

只输入两三个字（比如"预制菜"）可能不会自动触发技能，加一句"调研""深度调研""分析"或直接点名即可。

### 4. 修改默认口径：直接说

| 你想改 | 就这么说 |
|---|---|
| 地理范围 | "只看中国市场" / "重点看东南亚" |
| 重点方向 | "重点看政策和竞争格局，技术那块可以略" |
| 调研目的 | "目的是写文章" / "我要去面试" / "准备参会" |
| 时间范围 | "只看 2025 年以后的" |
| 输出形式 | "别存文件，直接说" |

**用户说的话永远覆盖默认值。**

## 默认口径（不说就按这个走）

| 项 | 默认值 |
|---|---|
| 地理范围 | **中国 + 全球对比**（至少含：中国在全球的位置、海外对标市场、中外差距及原因） |
| 重点方向 | **市场规模、竞争格局、技术演进、政策变化、商业模式、投融资动态**（六项全覆盖） |
| 调研目的 | **投资**（判断机会与可投性） |
| 时间范围 | 近 12 个月为主，关键趋势延伸 2–3 年 |
| 产业链范围 | 全链，但结论收敛到"最值得投的环节" |
| 周期位置 | 报告第二节必答"发展阶段 + 当前所处周期位置"（含与需求/库存/政策周期的关系）。**先按阶段判定表定标签**（七选一：四阶段 + 政策终止/技术终止/衰退后回稳），再写判断依据 |
| 交付形式 | 对话内输出 + 存一份 Markdown 到工作目录 |

**目的不同，第六节"机会点判断"的落点不同**：

| 目的 | 第六节会怎么写 |
|---|---|
| **投资（默认）** | 可投环节与标的类型、格局是否已定、瓶颈与定价权、周期位置、一级/二级市场可及性、退出路径 |
| 写文章 | 最有信息增量的 2–3 个反常识结论 + 可直接引用的硬数据 |
| 求职 | 哪些环节在扩招、什么能力稀缺、头部公司人才结构 |
| 参会/见人 | 对方最可能关心的争议点 + 你能提供的差异化信息 |
| 业务策略 | 切入点、进入门槛、最小可行路径、需要签下的关键资源 |

## 它会怎么工作（九步）

```
1 解析输入      拆出【行业】【特别关注点】，并回显一行"本次调研口径"给你核对
2 锁定口径      六方向 + 中国&全球 + 目的=投资（你指定的覆盖默认）
3 计划检索      按检索作战包生成查询清单（六方向 × 中外两套 + 关注点专项，不少于 15 条）
4 检索取证      搜索并读原文；付费墙挡住的换来源，自媒体只当线索
5 建证据台账    每条数据一行：数据 / 口径 / 来源 / 发布时间 / 类型 / 核实状态
6 双源核验      关键数字与结论 ≥2 个独立来源，否则标"待核实"并写明影响
7 反面证据      每个核心判断找最强反方证据，并列出关键假设
8 成稿          按七节结构 + 两个附录写
9 落盘与自检    存 Markdown → 十条自检 → 输出
```

**第一步之后它会直接开工，不会停下来等你确认**——只有三种情况会追问你：

1. 行业词跨度过大（如"教育""新能源""储能"，可拆成多个赛道）
2. 关注点里含"出海/落地"但没说目标市场（它会先按 1–2 个最可能市场并行取证，同时告诉你）
3. 输入只有极泛的词（如"消费""科技"）

**问不到你的时候（子 agent、批处理、自动化流程）它不会卡住**，而是降级执行并在报告首行写明"口径未经确认：本次采用 X 口径；若实际为 Y，则结论变为 Z"。

## 报告长什么样

七个主节 + 两个附录：

```
一、执行摘要           3–5 条，每条一个小标题 + 正文（都带数字和来源）
二、行业概览           定义与边界（多口径分别说明）、发展阶段与周期位置（含阶段判定表）、产业链结构
三、市场规模与增长     规模（标口径来源）、近3年增长与预测、驱动与制约、全球对照
四、竞争格局           份额、头部企业对比、近期动态、新进入者与替代者
五、趋势与风险         3–5 个趋势、2–3 个风险、政策与监管变化表
六、机会点判断         2–3 个切入点 + 对特别关注点的正面回答 + 门槛与挑战
七、信息源清单         每条来源标可信度等级（一级/二级/三级/线索）
附录 A：关键假设与反面证据
附录 B：信息缺口清单
```

**数据标注长这样**（这是报告里最常见的一行）：

> 中国预制菜市场规模 2024 年 4,850 亿元（某咨询机构《XX 蓝皮书》，2026-02 发布，**估算口径，仅 1 个来源，待核实**）

**冲突数据长这样**（不取平均）：

> 行业规模存在两个口径，**并列如下**：
> - 甲口径 4,200 亿元（协会，2025-03，产值口径，含出口）
> - 乙口径 2,100 亿元（咨询机构，2024-11，终端零售额，不含出口）
>
> 差异约 2 倍，主要源于是否含出口与环节归属。本报告在趋势判断中采用乙口径，在讨论产能与出海时采用甲口径。**两个口径不取平均——平均值没有对应的现实对象。**

**想直接看一份完整示例**：`references/example-report.md`（预制菜·广西落地出海的示范报告，含来源怎么标、冲突怎么并列、关注点怎么正面回答）。

## 特别关注点是怎么被回答的

关注点**不会被写成行业通识**，而是被拆成子问题逐个给依据。以"在广西落地出海机会在哪里？"为例，它会回答：

**广西有落地条件吗** → 查地方产业规模（并点明地方数据常见的三个坑：单一来源、口径不可比、把规划产能当实际产量）、地方政策原文、资源禀赋、龙头项目

**出海机会在哪** → 六个必查项逐条给状态：

| 必查项 | 要拿到什么 |
|---|---|
| 目标市场与规模 | 海关出口数据（按 HS 编码）、目标国进口统计 |
| 准入与合规 | 进口国官方食品法规与认证要求 |
| 关税与原产地 | HS 编码税率、RCEP/自贸协定适用条件 |
| 渠道结构 | 当地中餐供应链、商超、跨境电商 |
| 当地竞争 | 当地品牌与价格带 |
| 物流与成本 | 冷链出口成本占货值比例 |

**结论会被写成可验证的路径句**，而不是"出海有机会"这种空话：

> 走 XX 渠道进入 XX 市场，需先取得 XX 认证（依据 XX 官方文件，X 年 X 月），当前关税 X%（HS XXXX，X 年），对标当地 X 品牌价格带 X–X 元，物流成本占货值约 X%（来源，日期）。

数据不够时它会**明确说不够**，并给出从低成本到高成本的验证顺序——**而不是硬凑一个结论**。

## 常见问题

**Q：为什么它只是泛泛而谈，没有搜索动作？**
技能没被加载。回一句"用 industry-deep-research skill 重新调研"，它就会调用。只输入行业名两个字时自动匹配可能不触发，建议加上"调研/分析/深度研究"或直接点名。

**Q：报告里的数字能直接引用吗？**
看标注。标"**已核实（2 源）**"且来源是一级的，可以引用；标"**待核实（仅 1 源）**"的，引用时请保留"待核实"三个字；标"**估算**"的，必须写明是哪家机构估算、什么口径。**这份技能的价值恰恰在于它不会把所有数字都写得一样可信。**

**Q：为什么规模数据经常有好几个，还差好几倍？**
因为口径不同，**这不是数据矛盾，是问题不同**。行业规模至少四种算法：产值（含出口、含产业链重复计算）、出厂口径、零售额、GMV；再加是否含B端餐饮渠道、是否含主食类。技能的处理是**并列展示 + 说明各自适用场景**，而不是取平均或挑一个最好看的。

**Q：政策数据它会查原文吗？**
会优先查政府原文（部委公告、国家标准全文公开系统、地方政府文件），媒体解读只作补充。每条政策要写清：发布机构 + 文号/名称 + 发布日期 + 实施日期 + 对行业的实际约束（鼓励/限制/禁止）。

**Q：能只调研一个具体问题，不做整份报告吗？**
能。只要一个数字或一个事实时**不该启动整个流程**——直接问它就行，它会直接检索回答。反过来，想深挖报告某一节可以说"展开第三节""把竞争格局再挖深一点"，它只补检索该节、输出增量，不重写全篇。

**Q：调研传统行业（农业、农产品加工、地方制造业）时，"投融资动态"那一节为什么不是融资事件？**
因为这类行业**本来就不靠股权融资**。它的钱来自财政补贴、政策性信贷、产业资本扩产和企业自筹。所以技能里有一条**降级规则**：搜"融资/IPO/并购"连续 4 条查询没有事件级结果时，自动切换到**资金结构**分析，逐类检索五类资金，并把结构翻译成投资含义：

| 资金结构特征 | 投资含义 |
|---|---|
| 政府财政主导 | 政策变动即现金流断点，补贴退坡会击穿单位经济模型 |
| 产业资本密集扩产 | **产能过剩前兆**（尤其扩产主体"此前无行业经验"时，是热钱特征） |
| 银行信贷为主 | 利润对利率与抵押物估值敏感 |
| 股权融资罕见 | 退出依赖并购或股权转让，而非 IPO |
| 地方产业基金已进场 | 有政府定价参照，但常附带返投与落地条件 |

**为什么要有这条**：只搜融资事件然后写"未找到"，会同时犯两个错——漏掉真实存在的资金形态，以及**把"融资事件少"误读成"行业不热"**。而对投资判断来说，财政资金和产业资本密集进入往往意味着新一轮扩产，是**过剩的前兆**，跟"行业不热"正好相反。

**Q：技能说"未找到"和"未覆盖"不是一回事，为什么强调这个？**
因为这两种"没有"的含义完全不同：
- **"已查无"**＝我搜过了（会列出检索词与查过的来源类型），确实罕见 → 可以写成判断
- **"未覆盖"**＝我压根没搜这一类 → 只能写成检索状态，**不能暗示它不存在**

所以报告里凡写"未找到"的地方，都会带上检索状态。这是为了让你知道**该不该自己去补一次检索**。

**Q：它会自动更新数据吗？**
不会。技能是静态流程文件，数据靠每次调研实时检索。**技能文件本身也不会自动更新**，你手动替换文件夹才会。

**Q：我改了技能内容，怎么确认没改坏？**
跑一下目录里的自检脚本，**只读、1 秒出结果**。脚本自动定位自身所在目录，所以在哪台机器、哪个路径都能跑：

```
# 推荐：先接住退出码，再决定要不要看输出
$out = & (Join-Path $env:USERPROFILE '.dsh\skills\industry-deep-research\自检.ps1')
if ($LASTEXITCODE -ne 0) { $out | Select-String 'FAIL' }
```

也可以先 `cd` 进技能目录再 `& .\自检.ps1`。

> ⚠️ **别用点源**（`. .\自检.ps1`）——那样失败会被吞掉、进程退出码恒为 0。退出码必须**紧接调用后**取。
>
> 依赖：Windows PowerShell 5.1 或 PowerShell 7 均可（本机实测 5.1）。严格 YAML 解析需要 `node` + DSH 自带的 `yaml` 包；缺任一则该项报 **FAIL**（不会静默放过），此时其余检查照跑。

它会检查 **162 项**，覆盖七类：
| 段 | 查什么 |
|---|---|
| **A** | 8 个文件是否齐全 |
| **B** | frontmatter 是否合法（name 必须全小写 kebab-case、description ≤500 字符、YAML 能否解析） |

**Q：能装到别的 AI 工具（Claude / ChatGPT / Kimi / Gemini）吗？**
不能直接用——这是 DSH 的技能格式。请改用同目录下的 `单文件通用版提示词.md`（约 5,000 字 / 3,100 tokens），整段粘进任何支持联网的 AI 即可。它自带全套规则：双源核验、18 个月时效、口径并列不取平均、反面证据、四档置信度、投融资降级、信息缺口清单。

**Q：和已经装好的 `industry-lifecycle-analyzer`（行业生命周期判断器）什么关系？**
配合用，不冲突：
- **判断"这个行业处在什么阶段、还能不能进"** → 用 `industry-lifecycle-analyzer`（五指标投票 + 渗透率校准，输出更聚焦、更锐利）
- **要一份完整调研报告**（规模、格局、政策、投融资、机会点、出海） → 用 `industry-deep-research`
- 深调研里如果发现阶段判断有争议，可以顺手调生命周期技能单独判一次阶段，把结论嵌进报告第二节

## 怎么分享给别人

技能就是**一个普通文件夹**（9 个文件、约 140 KB），没有任何安装脚本、没有外部依赖，拷过去就能用。

> **转发时提示对方先看 `README.md`**——那是专门写给接收方的说明（约 8 KB），只讲"是什么、怎么装、怎么用、用之前该知道什么"，不含维护与自检这些开发内容。本文件（`使用说明.md`）是完整版，字数是它的 3 倍，直接发给同事容易劝退。

### 方式一：整个文件夹（推荐，功能完整）

把 `industry-deep-research` 文件夹拷到对方的 DSH 用户技能目录：

| 系统 | 路径 |
|---|---|
| Windows | `%USERPROFILE%\.dsh\skills\industry-deep-research\` |
| macOS / Linux | `~/.dsh/skills/industry-deep-research/` |

**不用重启、不用安装命令**——DSH 按文件系统扫描，对方下一个会话轮次就能在技能清单里看到。

**对方怎么确认装好了**：新开对话问一句 `industry-deep-research 这个技能是干什么的？`，能说出"逗号前是行业、逗号后是关注点"就装好了。

### 方式二：压缩包

打包好的 `industry-deep-research-skill.zip` 直接发给对方，解压后把文件夹放进上面的路径即可。

### 方式三：只要提示词（不装 DSH 的人）

把 `单文件通用版提示词.md` 的内容整段发给对方，让他粘进 ChatGPT / Claude / Kimi / Gemini 等**支持联网**的 AI 即可，规则与技能版等价。

### 分享前要注意的三件事

| 事项 | 说明 |
|---|---|
| **别只发 SKILL.md** | 它引用了 `references/` 和 `assets/` 下的 4 个文件，单独发会导致执行时读不到检索包与模板。**必须整个文件夹一起给**。 |

## 已知局限（技能内置，会主动向你说明）

1. **AI 检索的覆盖度与质量不稳定**——未搜到不等于不存在，报告会写明检索范围
2. **行业规模类数字普遍存在多口径**——报告里的口径差异是真实差异，不是误差
3. **政策与监管变化时点难以预测**——报告只描述现状与已公布方向，"市场预期"会单独标注
4. **未披露的融资额、未上市企业财务、地方产业数据常有系统性缺失**——这些会进信息缺口清单，不会用模糊值填充
5. **涉及具体投资标的时，本报告不能替代尽调、财务与估值分析**
6. **结论基于公开信息，不构成投资建议**
7. **投融资维度对传统行业与农产品加工行业的信息可得性最差**——这类行业的钱主要来自财政补贴、政策性信贷、产业资本与自筹，股权融资事件本身就罕见。报告遇到这种情况会**降级为"资金结构"分析**（政府财政／银行信贷／产业资本／自筹／行业基金五类）并翻译成投资含义；但其中**财政补贴金额、信贷条件、自筹比例往往不公开**，这部分通常只能定性描述
