# 检索作战包

> **本文件解决的核心问题**：**检索深度不足会直接导致报告到处写"未取到"。** 实测教训——曾给子任务设"检索控制在 20 次以内"，结果报告出现大量数据缺口。**本技能不设检索次数上限**，只设**覆盖度下限**。

---

## 零、零号动作：先把参考坐标定下来

动手检索前先定三件事，否则后面每一轮都在猜：

| # | 动作 | 说明 |
|---|---|---|
| 1 | **定类型** | 行业调研／产业链调研（见 SKILL.md 第 2 节）——**类型决定检索方向** |
| 2 | **定坐标** | 先找到 2–3 篇**行业综述或券商研报**，把"这个行业的常用口径、主要玩家、关键指标"摸一遍——**它们是最好的检索词来源** |
| 3 | **定口径** | 明确本次用哪个口径（如"出厂额"还是"终端额"）——**口径不定，后面所有数字都不可比** |

## 一、检索深度要求（★这是本作战包最重要的部分）

### 1.1 🔴 检索量硬性区间：**最少 100 个网站链接，最多 500 个**

**这是本技能对检索量的强制要求——低于下限视为检索未完成，报告不得交稿。**

| 项 | 要求 |
|---|---|
| **网站链接总数** | **下限 100 个，上限 500 个** |
| **计数口径** | **每条实际打开或读取过的 URL 计 1 个**（含 web_search 返回的来源页、web_fetch 打开的原文、官方接口调用、PDF 原文）。**同一域名下的不同页面分别计数**；**未打开、仅出现在摘要里的不算** |
| **配比建议** | 其中**至少 40 个必须 web_fetch 打开原文**（不能只看搜索结果摘要）；**至少 20 个为一手来源**（政府/统计/企业公告/招股书/标准原文/券商研报 PDF） |
| **多语种** | 涉及国际对标时，**用目标国语言检索**（日本用日文、韩国用韩文、全球用英文）——**外语来源本身也计入链接数** |
| **多问法** | 同一问题**至少换 3 种问法**（如"虾滑 市场规模"／"虾滑 行业规模 亿元"／"shrimp paste China market size"） |
| **为什么设上限** | **超过 500 个通常意味着重复劳动或跑偏**——此时应回头检查检索方向是否发散，而不是继续堆量 |

> ⚠️ **低于 100 个链接的后果**：报告会出现大量"未取到"，**这是本技能实测过的头号质量问题**（曾给子任务设"20 次以内"，结果报告到处是数据缺口）。
>
> ⚠️ **分工检索时按路数摊派**：若把调研拆成 4 路，**每路至少要 25 个链接**（4 × 25 = 100），并向技能说明每路实际打开的链接数。

### 1.2 链接数台账（★交稿时必须能报出这个数）

**边检索边记**，交稿前汇总：

| # | 类型 | 计数规则 | 本次数量 |
|---|---|---|---|
| 1 | **web_search 返回并实际查看的来源页** | 每个 URL 计 1 | |
| 2 | **web_fetch 打开的原文** | 每个 URL 计 1（含 PDF） | |
| 3 | **官方接口调用** | 每个接口 URL 计 1（如 F10 每家 1 条） | |
| 4 | **一手来源**（政府/统计/公告/招股书/标准/研报 PDF） | 从上述中划出，**不重复计数** | |
| — | **合计（去重后）** | **须落在 100–500 之间** | |

> ⚠️ **报告末尾的「方法与数据来源说明」必须写出这个合计**（如"合计读取 **187 个网站链接**，其中一手来源 43 个"）。
> **报不出这个数 = 无法证明达到下限 = 交稿不合格。**

### 1.3 缺口驱动的补检索（★方法）

**不要"检一轮就写报告"。** 正确做法是**先列出目标字段，再逐个消灭缺口**：

```
① 列出报告需要的全部字段（按模板的表格列）
        ↓
② 对每个字段做检索，记录"取到/未取到"
        ↓
③ 对"未取到"的字段，换问法、换语种、换来源层级，再检索
        ↓
④ 仍取不到 → 记录"已尝试的检索词"，写进附录 B 的"已尝试检索"列
        ↓
⑤ 判断：这个缺口是否导致某条结论不成立？是则写进摘要的"关键缺口"
```

> ⚠️ **"已尝试检索"列不可省**——它区分"没找到"与"没找"。**没找是失职，没找到是客观限制。**

### 1.4 一手来源优先（取证顺序）

| 优先级 | 来源类型 | 说明 |
|---|---|---|
| **1** | **政府与统计** | 统计局、农业农村部、海关总署、地方统计公报、行业协会年鉴 |
| **2** | **企业一手** | 年报/半年报、招股书、公告、业绩会记录、**财报分部附注** |
| **3** | **券商研报** | 有署名的行业深度报告（**优先 PDF 原文**） |
| **4** | **标准化文件** | 国标/团标原文、政策文件原文（**注意施行日期**） |
| **5** | 财经媒体 | 有署名与日期的报道 |
| **6** | ⚠️ **转引** | **只作线索，不得作为最终来源**——须回溯到原始出处 |

> 🔴 **转引是最大的错误来源**。实测：某数字经多家媒体互相转引后被挂到错误机构名下、年份也被改动。**见第四节的口径分层规则。**

## 一·五 🔴 关键词构造与渠道匹配（★本节决定"数据全不全、准不准"）

> **实测教训**：本技能早期只规定"每个方向要检索什么"，结果**检索量上去了、数据仍然不准**。
> 原因：**把"分析维度"直接当成了"检索词"**。
> 本节据外部实践修正：**先构造关键词，再匹配渠道**；**分析维度不是检索词**。

### 1.5.1 关键词四槽组合公式

**每个检索式由四个槽位组合**，缺一即覆盖面不全：

```
【对象名称】＋【业务/指标】＋【地域】＋【时间】
```

| 槽位 | 填什么 | 例（虾滑） |
|---|---|---|
| **对象名称** | 行业/品类/公司/环节名 | 虾滑、冻虾滑、虾糜制品 |
| **业务/指标** | **销量、收入、价格、产能、用户数、企业数、份额** | 产量、出厂价、规上企业数 |
| **地域** | 全国／省／市／国别 | 广西北海、广东湛江 |
| **时间** | 年份／季度／"最新" | 2025、2026H1 |

> ⚠️ **指标槽是重点**——**多数"数据缺失"不是没搜，而是只搜了"市场规模"这个词，没搜"产量/价格/产能/企业数"**。
> 金额数据缺失时，**改搜物理量**（吨、台、亩、头）或**改搜企业数**，往往能绕过口径谜团。

### 1.5.2 六维扩展（每个对象名称都要展开）

| 维度 | 说明 | 例 |
|---|---|---|
| **中文全称** | 官方名称 | 速冻虾滑 |
| **英文名** | 用于国际对标与英文来源 | frozen shrimp paste / shrimp surimi |
| **简称／俗称** | 行业口头叫法 | 虾滑、手打虾滑 |
| **旧称** | 历史名称（年鉴口径常不同） | 虾丸 |
| **同义词** | 近义表述 | 虾糜制品、虾糜 |
| **上下位概念** | ⚠️ **上位词查总量、下位词查细分** | 上位：水产预制菜／速冻调制食品；下位：虾滑串、虾排 |

> 🔴 **上下位概念是最容易被忽略、却最有效的一维**：
> - 直接搜"虾滑市场规模"往往只有机构估算 → **改搜上位词**（水产预制菜、速冻调制食品）拿**官方统计**，再按占比拆
> - 直接搜"虾滑竞争格局"无果 → **改搜下位**（虾滑串、虾排、虾肠）看谁在做，**反推玩家**
> - 换语言：日本市场用日文（魚肉練り製品）、韩国用韩文（어묵）、东南亚用英文

### 1.5.3 🔴 反模式：不得把「分析维度」直接转成「必搜词」

| ❌ 错误做法 | ✅ 正确做法 |
|---|---|
| 看到骨架有"技术演进"→ 就去搜"技术演进" | 搜**具体材料**：技术路线名、工艺名称、专利、设备型号、标准编号 |
| 看到"竞争格局"→ 就搜"竞争格局" | 搜**销量、份额、产能、企业数、TOP5 名单** |
| 看到"商业模式"→ 就搜"商业模式" | 搜**渠道结构、客户集中度、单位经济、加价率、账期** |
| 看到"政策变化"→ 就搜"政策" | 搜**文件名、文号、实施日期、强制性条款** |

> **判据**：**"分析维度"是你脑子里的分类，不是世界上的词。** 世界上存在的词是**产品名、指标名、机构名、文件名、公司名**。
> ⚠️ **本技能第 2.1／2.2 节的两张"报告节 → 检索什么"表，是**检索**方向提示，不是关键词模板**——**用它确定方向，再用 1.5.1／1.5.2 构造词**。

### 1.5.4 材料类型 → 渠道匹配表（**核心**）

**不同材料类型必须从对应渠道取**——用错渠道就会拿到二手转引或估算值。

| 材料类型 | 优先渠道 | 不要用 |
|---|---|---|
| **官方统计（量、额、企业数、产能利用率）** | 国家统计局、地方统计局、统计年鉴、行业协会年鉴 | 咨询机构摘要页 |
| **行业代码与口径** | GB/T 4754 原文、统计局指标解释 | 媒体解读 |
| **海关与进出口** | 海关总署分章/分品目统计、分国别量额价 | 行业报告转述 |
| **政策与监管原文** | 部委/地方政府公告、**文号、实施日期** | 新闻稿解读 |
| **国家标准/团标** | 国家标准委、全国团体标准信息平台**原文** | 媒体摘要 |
| **公司披露** | 交易所公告、年报/半年报**分部附注**、招股书、业绩会记录、投资者关系页 | 财经媒体转述 |
| **分部财务（毛利率/收入结构）** | **官方接口**（见 1.5.6）、财报分部附注、XBRL | 研报二手引用 |
| **交易与并购（金额、估值）** | 交易所公告、并购重组报告书、**明细可验证者优先** | 媒体标题 |
| **破产/退出** | 全国企业破产重整案件信息网、法院裁定 | 行业传闻 |
| **招投标与采购** | 政府采购网、招标公告、中标公告、合同 | 新闻综述 |
| **专利** | 国家知识产权局、专利数据库 | 企业宣传页 |
| **论文与技术** | **arXiv 网站或 API（涉学术/算法/AI/前沿技术时必查）** | 科技媒体 |
| **用户声音/痛点** | 原帖与社区语境（保留原帖、时间、互动数据） | 二手汇编 |

**PEST 四维的分渠道优先**（做 PEST／政策环境时用）

| 维 | 优先渠道 |
|---|---|
| **P 政治政策** | 政府、立法、监管、海关、贸易、国际组织**原文** |
| **E 经济** | 统计与调查**原表 + 方法说明** |
| **S 社会** | 统计与调查原表、抽样说明 |
| **T 技术** | **论文、标准、专利、产品与部署材料** |

> ⚠️ **政策目标、经济指标、社会讨论、技术进展不能直接代替"已经发生的行业影响"**。

### 1.5.5 专项检索方向库（按研究对象类型选）

**产业链／环节关系**（做产业链报告用）

```
【环节/角色名】＋供应商／客户／采购／销售／合同／中标／合作／年报／招股书
【具体产品/技术/服务】＋生产／产能／产线／扩产／投产／环评
```

**行业痛点**

```
围绕六向：承担者／任务／损失／现有替代／失败／放弃
```

**驱动力（解释为什么涨或跌）**

```
围绕五向：目标行业结果／候选原因／时滞／反例／替代解释
```

**投资逻辑**

```
按论点卡安排：论点｜关键变量｜支持与反证材料｜能区分两种解释的证据｜对选择的影响
```

> ⚠️ **示例**：检验"增长来自持续需求还是一次性备货"，应比较**终端销售、客户库存、复购**，**而不只搜收入新闻**。

**竞品与份额**

```
【品类】＋销量／销售额／市占率／CR5／TOP5／产能／出货量／经销商
```

### 1.5.6 分部财务的官方取数法（**本技能头号硬资产，勿丢**）

```
https://emweb.securities.eastmoney.com/PC_HSF10/BusinessAnalysis/PageAjax?code={SH|SZ|BJ}{6位代码}
```

| 字段 | 内容 |
|---|---|
| `zygcfx` | 主营构成：分产品/分地区收入、成本、**毛利率** |
| `MAINOP_TYPE` | 1=按行业 2=按产品 3=按地区 |
| **`GROSS_RPOFIT_RATIO`** | **分部毛利率**——接口把 PROFIT 拼成 RPOFIT，**写成 `GROSS_PROFIT_RATIO` 取不到值** |

> 🔴 **头号陷阱**：多个维度**各自都等于总营收**，**跨维度相加会放大 2–3 倍**。**只取单一维度**，并核对分部收入之和 ≈ 公司总营收。

**其他可用结构化数据能力**（存在则用，不存在则跳过，不虚构）

| 能力 | 用途 | 注意 |
|---|---|---|
| 交易所结构化数据 / XBRL | 多期财报提取与标准化 | **必须回到法定披露核对字段映射、期间、单位** |
| OpenBB / EdgarTools / FinanceToolkit 等 | 加快财报提取与比率计算 | 同上；**自动映射只用于提效，不替代原文** |

### 1.5.7 失败渠道必须记录（**"已安装"≠"调用成功"**）

| 项 | 要求 |
|---|---|
| **记录什么** | 只记录**会影响覆盖或结论**的失败、限制与替代路径；不记录无关报错 |
| **记在哪** | 附录 B 的「已尝试检索」列 + 搜索记录 |
| **区分三件事** | **"已安装"／"已配置"／"本次实际调用成功"** —— **不是一回事** |
| **失败后的动作** | 换其他可用能力补齐；**不得因一次失败就写"未取到"** |
| **降级要标明** | 用户禁止联网或渠道全失败时，**在交付物中说明缺口** |

### 1.5.8 独立性判定（防"伪双源"）

| 情形 | 判定 |
|---|---|
| 两家媒体**转载同一原文** | 🔴 **不是独立来源** |
| 多家媒体**同引一家机构** | 🔴 **不是独立来源**，须记该机构为唯一来源 |
| 咨询机构**摘要页**与其报告正文 | ⚠️ **同一来源** |
| 统计局原表 vs 券商据此测算 | ⚠️ **同源**（券商是派生） |

> ⚠️ **不同数据库转载同一原文也不是独立来源。**
> ⚠️ **注意角色混淆**：**设备生产者、使用者、经销商、维修商可能使用同一关键词**；经营范围中出现"维修"**不代表它只是维修商**；**专利支持技术线索、招投标需辨认采购/投标/中标角色，均不能直接替代实际经营证据**。

## 二、按报告类型定检索方向

### 2.1 行业调研报告（十一节）的检索方向

| 报告节 | 要检索什么 | 检索词示例 |
|---|---|---|
| 一 定义与统计口径 | 分类代码、官方定义、标准体系 | "[品类] 国民经济行业分类"、"[品类] 国标 标准号"、"[品类] 定义 通知" |
| 二 市场规模 | 多口径规模、**逐年序列**、量价拆分 | "[品类] 市场规模 亿元"、"[品类] 产量 万吨"、"[品类] 增速 同比" |
| 三 阶段判定 | 五指标所需数据 | "[行业] 企业数量"、"[行业] 产能利用率"、"[行业] 亏损 退出" |
| 四 渗透率 | **当期**渗透率、国际对照 | "[品类] 渗透率"、"[品类] 渗透率 美国 日本" |
| 五 竞争格局 | **集中度**、企业总数、头部份额 | "[品类] CR5"、"[品类] 市场份额"、"[品类] 行业集中度" |
| 六 壁垒与依赖 | 技术门槛、认证周期、**进口依赖度** | "[品类] 进口依赖"、"[品类] 国产化率"、"[行业] 认证 周期" |
| 七 区域分布 | 集聚区、**国家级头衔**、集群产值 | "[品类] 产业集群"、"[地区] [品类] 产值"、"[品类] 优势特色产业集群" |
| 八 政策 | 政策原文、**施行日期**、强制/鼓励 | "[品类] 政策 通知"、"[品类] 国标 实施日期" |
| 九 机会点与策略 | **新进入者路径**、**差异化案例**、并购退出 | "[品类] 新品牌 突围"、"[品类] 差异化"、"[品类] 并购"、"[品类] IPO" |
| 十 趋势与风险 | 趋势成因、**先行指标** | "[品类] 趋势"、"[品类] 风险"、"[品类] 价格走势" |

### 2.2 产业链调研报告（十一节）的检索方向

| 报告节 | 要检索什么 | 检索词示例 |
|---|---|---|
| 一 链的结构 | 上中下游切分、各环节代表企业 | "[链条] 产业链 上游 中游 下游"、"[环节] 主要企业" |
| 二 环节级利润 | **各环节分部毛利率** | 用第一节的**官方接口**批量取数；辅以"[企业] 分部 毛利率" |
| 三 逐环节集中度 | 每环节自己的 CR 与玩家数 | "[环节] 集中度"、"[环节] 主要企业 份额" |
| 四 出清机制 | 并购、破产、标准、渠道集中 | "[环节] 并购"、"[环节] 破产 重整"、"[环节] 标准 等级" |
| 五 技术壁垒 | 技术门槛、替代风险 | "[环节] 技术壁垒"、"[环节] 技术路线" |
| 六 国产替代 | 卡点、国产化率、参与者 | "[零部件] 国产化率"、"[材料] 进口依赖"、"[卡点] 替代" |
| 七–九 落点/迁移/区域 | 价值迁移、环节区域集聚 | "[环节] 集中 地区"、"[环节] 产能 分布" |
| 十 趋势与风险 | 只检索**影响环节成本/准入/格局**的 | "[环节] 成本"、"[环节] 准入 政策" |

### 2.3 两种类型共用的专项

**中国 + 全球对照法**：每个关键指标都问一次"全球/主要国家是多少"——**对照能暴露国内口径的异常**（如国内渗透率远低于国际时，要么是空间，要么是口径问题）。

**区域落地与出海专项**（关注点涉及区域或出海时必做）

| 子项 | 查什么 |
|---|---|
| 区域落地 | ① 区位与资源禀赋 ② 地方政策与补贴（**含文号与日期**）③ 本地龙头与产业链配套 ④ 物流与成本 ⑤ 与主要市场的距离 |
| **出海六项必查** | ① 目标市场与准入路径（**官方依据**）② **关税/原产地规则/合规要求（含税率与年份、HS 编码）** ③ 渠道结构与切入点 ④ 当地竞争格局与价格带 ⑤ 物流与成本结构 ⑥ 区域资源禀赋与地方政策 |

> ⚠️ **出海六项缺一项视为未完成**——只写"可以出海"而不写关税与原产地规则，是无法执行的建议。

## 三、口径分层与来源核验（★与报告质量直接相关）

见 `references/来源核验与证据台账.md` 的完整规则。此处只强调**据以检索的三条**：

### 3.1 先分三层，再判断"冲突"

| 情形 | 特征 | 处理 |
|---|---|---|
| **口径分层** | 差异可由**统计层级**解释（终端／出厂／TAM／零售） | **分别标注层级**，**不得写成"冲突"** |
| **真冲突** | 同一层级、同一基准年、方向相反或差异过大且无层级可解释 | **并列、不取平均**，写明差异与成因 |
| **同源（伪独立）** | 同一来源，或多个媒体互相转引 | **按共线处理**；**回溯到最早出处** |

### 3.2 检索时必须做的三件事

1. **回溯最早出处**——不要引用转引；转引会继承错误（实测：某数字被转引后挂错机构、改错年份）
2. **检查署名**——**无机构署名的数字要标注"无机构署名"**
3. **检查层级**——数字超出同层级合理倍数（如出厂口径出现 5 倍差）时，**先怀疑层级不同，而不是"口径冲突"**

## 五、材料词库（**供构造检索式用，不是分析维度词**）

> 🔴 **本节与 1.5.3 一致**：下列词是**材料类型**（销量、价格、产能…），**不是分析维度**（不是"市场规模""竞争格局"这些分类名）。
> **用法**：用 1.5.1 的四槽公式，从本表取"指标槽"的词，与对象名称组合。

### 5.1 量值类（金额数据缺失时优先改搜这些）

| 材料词 | 常见来源 | 能推出什么 |
|---|---|---|
| 产量、出货量、销量（吨／台／亩／头） | 统计局、行业协会、公司公告 | 量 × 价 = 额；**绕过金额口径谜团** |
| 产能、在建产能、产能利用率 | 环评公示、地方项目公示、公司公告 | 判断过剩程度与出清压力 |
| 企业数、规上企业数、亏损面 | 统计局、工商注册、地方公报 | 判断集中度与出清 |
| 装机量、保有量、存量 | 主管部门统计 | 更新需求 = 保有量 × 更换率 |
| 用户数、客户数、门店数、床位／席位 | 公司披露、主管部门统计 | 单位经济与 TAM 分母 |
