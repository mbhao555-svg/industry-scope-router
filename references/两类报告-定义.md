# 行业调研报告 与 产业链调研报告 的区分（定义与使用规则）

> **本文件是"两类报告"的唯一权威定义。** 与《行业与产业-定义》配套使用——**先定分析单位（行业／产业），再定报告类型**。

---

## 一、一句话定义

| | **行业调研报告** | **产业链调研报告** |
|---|---|---|
| **分析单位** | **行业**（统计分类口径） | **产业链**（价值流转） |
| **回答的独有问题** | **这个行业整体值不值得进？** | **这条链上投哪一段、绕开哪一段？** |
| **一句话概括** | 判**这门生意** | 判**这条链的位置** |

> ⚠️ **两者都是投资分析，但回答的不是同一个问题。** 一个行业可以"整体不值得进，但链上某一段值得投"（预制菜即例：行业成长期但中游是利润洼地）；也可以"整体值得进，但每一段都不好投"（高度同质的成熟行业）。

---

## 二、结构对照（哪些部分是各自独有的）

| 报告部分 | **行业调研报告** | **产业链调研报告** |
|---|---|---|
| 定义与统计口径 | ✅ **必做核心**（分类代码、统计口径、官方边界） | ⚠️ 简略（只需说明链的边界由谁划定） |
| **市场规模** | ✅ **必做**（总量、增速、多口径并列） | ❌ **不需要独立成节**（环节收入之和即链规模，且无官方总量） |
| **渗透率** | ✅ **必做**（校准阶段上界） | ❌ **不适用**（单环节没有渗透率） |
| **行业阶段判定** | ✅ **核心产出**（五指标投票 → 一个标签） | ⚠️ 可选；**若给，须用该环节自身信号** |
| **集中度（CR3/5/10）** | ✅ **必做**（判格局与出清） | ⚠️ 逐环节做（各环节集中度可完全相反） |
| **产业链结构拆解** | ⚠️ 可选（若行业本身是一条链） | ✅ **必做核心** |
| **环节级利润分布** | ❌ **不要求** | ✅ **核心产出**（毛利率逐环节） |
| **出清机制** | ✅ 行业层五问（一个档位） | ✅ **逐环节**五问（每环节自己的档位） |
| **投资含义矩阵** | ⚠️ 行业级（阶段 × 出清） | ✅ **逐环节落点** |
| **区域集群对照表** | ✅ 常用 | ⚠️ 可选 |
| **政策沿革** | ✅ **必做**（行业受政策直接约束） | ⚠️ 只做影响环节成本/准入的部分 |

**灰色地带（两者都可能做，但做法不同）**：竞争格局、趋势与风险、国际对比。
行业报做**整体份额与整体趋势**；产业链报做**逐环节份额与环节间价值迁移**。

---

## 三、核心产出的差异（这是最实用的判据）

| | **行业调研报告的核心产出** | **产业链调研报告的核心产出** |
|---|---|---|
| 1 | **行业阶段**（导入/成长/成熟/衰退）+ 置信度 | **环节级利润分布**（环节 → 毛利率 → 来源 → 样本量） |
| 2 | **渗透率**及其所在档位、是否触发硬规则 | **出清机制逐环节**（五问 × 环节 → 档位） |
| 3 | **集中度与格局**（CR3/5/10 及其趋势） | **投资含义矩阵逐环节落点**（可投／规避／绕开） |
| 4 | **行业级投资结论**：进／不进／等什么条件 | **环节级投资动作**：投哪一段、绕开哪一段、以及**失效条件** |
| **判据** | 若删掉第 1–3 项，报告就答不出它的问题 | 若删掉第 1–3 项，报告就答不出它的问题 |

---

## 四、一个必须遵守的规则：**两层判断不得混在一份报告里而不声明**

### 4.1 问题

**实测**：本工作区的两份投资分析报告都**同时**给出了"行业阶段判定"与"环节落点"，**但都未声明两者关系**。读者看到"行业判成长期"又看到"中游肉制品判成熟期"，**无法判断是否自相矛盾**。

### 4.2 三种合规做法（择一，并显式声明）

| 做法 | 适用 | 声明写法 |
|---|---|---|
| **① 纯行业报告** | 只判行业值不值得进 | 不出现环节级结论；若要提环节，只作为"结构性说明"并注明**不构成环节判断** |
| **② 纯产业链报告** | 只判投哪一段 | **不给行业阶段标签**；或用"链的整体景气"这类**非阶段**表述；渗透率**不出现** |
| **③ 混合报告（两者都要）** | 投资分析通常如此 | **必须加一段"两个层面判断的关系"声明**（见 4.3） |

### 4.3 混合报告的标准声明段（可直接复制）

> **关于本报告两个层面判断的关系**
>
> 本报告给出 **①行业级**阶段判定（基于全行业汇总数据：增速、企业数量、渗透率、政策口径）与 **②环节级**可投性判定（基于各环节分部财务数据与出清机制）。
>
> **两者不矛盾，也不可互相推导**——行业阶段回答"这个行业整体处于什么周期位置"，环节落点回答"这条链上哪一段能投"。
>
> **数据不得跨层使用**：行业判定只用行业级数据；环节判定只用环节级数据。**渗透率校准仅适用于行业层，未跨层套用到任何环节。**
>
> 因此本报告可能出现"**行业判成长期、某环节判成熟期**"的并列结论——**这是两个层面的正常差异，不是自相矛盾**。

## 五、数据不可得的处置差异（决定报告能否成立）

| 情形 | **行业调研报告** | **产业链调研报告** |
|---|---|---|
| 该"行业"**在统计分类中无代码** | 🔴 **报告降级为"产业报告"**——无官方汇总数据，行业级结论（规模、渗透率、CR）全部不成立 | ✅ **照常做**——产业无需官方代码（预制菜即例） |
| 行业**有代码但汇总数据不披露** | ⚠️ 用机构估算，**必须标"口径不明/估算"**，阶段置信度降为中 | ✅ 不影响——本就不依赖汇总数据 |
| **环节分部数据取不到** | 不影响 | 🔴 **该环节结论不成立**，须标"需另行取证"并**不给可投性判断** |
| **渗透率取不到** | ⚠️ 不做校准，**但不得因此拒绝判阶段** | 不适用 |

## 六、判断流程（先定类型，再选结构）

```
① 用户问的是什么？
      "这行业能不能进／前景如何"           → 行业调研报告
      "这条链上哪一段能投／钱在哪"          → 产业链调研报告
      "能不能投"（笼统）                  → 混合报告（④），必须加 4.3 声明
② 查对象是否有官方分类代码？
      有 → 可出行业报告
      无 → 只能出产业链报告（或行业部分降级）
③ 按类型取数据：
      行业报告 → 汇总序列（营收/企业数/渗透率/CR）
      产业链报告 → 逐环节分部数据（F10 接口）
④ 下结论前自检：
      - 这份报告的核心产出（第三节）齐了吗？
      - 若混了两层，加 4.3 声明了吗？
      - 有没有把行业数据用到了环节结论上？／把渗透率用到了环节上？
```

## 七、术语使用纪律

| 禁写 | 改为 |
|---|---|
| "行业产业链" | 依类型写"**行业**"或"**产业链**" |
| "产业链的行业阶段" | 行业报告写"**行业**阶段"；产业链报告**不写阶段**（或写"该**环节**的周期位置"） |
| "各环节的行业集中度" | "**各环节**的集中度" |
| 在产业链报告里写"行业增速"当作环节增速的依据 | 必须给出**环节级**增速证据 |

## 八、本定义与《行业与产业-定义》的关系

| | 《行业与产业-定义》 | 本文件 |
|---|---|---|
| 解决 | **分析单位是什么**（行业 vs 产业） | **报告该长什么样**（行业报告 vs 产业链报告） |
| 顺序 | **先读** | 后读 |
| 共同约束 | 行业级数据不得用偏环节；渗透率不跨层 | 两层判断混用时必须声明（第 4 节） |

**两句话记住**：

1. **行业判"这门生意"，产业链判"这条链的位置"。**
2. **混着做可以，但必须声明两层关系，并保证数据不跨层。**
