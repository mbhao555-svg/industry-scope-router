# 报告模板（行业版 / 产业链版）

**使用说明**
- 把 `[方括号]` 换成实际内容；**不适用的条目删除而不是留空**，并在附录 B 说明原因。
- 带 ⚠️ 的字段是**硬要求**，缺一项视为报告未完成。
- **先按 SKILL.md 第 2 节判定类型**，再选对应模板。**混合报告**须加附录 D 的两层关系声明。
- **判据一律以 `references/` 下的文件为唯一权威**（阶段判定见 `阶段判定与投资含义.md`；产业链见 `产业链与出清机制.md`；来源核验见 `来源核验与证据台账.md`）。**本模板只规定"填什么"，不重复阈值与判据**——改规则只改那一个文件。
- ⚠️ **本模板中的旧节号映射**：旧模板的"2.2 发展阶段与周期位置"在本技能里拆到**行业版第三节**与**产业链版第四节/第五节**，判据内容不变，见下方对照。

```markdown
### 3.3 渗透率校准（⚠️ 无渗透率概念则改用替代指标并说明）

| 项 | 填写 |
|---|---|
| **判断问题**（先声明） | [增长还有多大空间 / 新增是否见顶 / 全球阶段 / 出口天花板] |
| **★口径先判** | [**存量渗透率**（已采用 ÷ 适用，答"一共装了多少"）/ **流量本期采用率**（本期启动采购 ÷ 可服务，答"本期多少人在买"）] |
| **主口径** | [存量保有 / 销量 / 全球 / 出口]，**只用于触发硬规则** |
| **读数与档位** | [数值] → [档位]；是否落在**临界点**（15–20% 或 35–40%） |
| **深度校验**（>60% 时必做） | 单位消费强度 = [数值]，分母口径 = [活跃 A / 潜在 B] |
| **硬规则是否触发** | [未触发 / 触发规则一 / 触发规则二]；**触发则写明冲突点三项** |

> 🔴 **存量与流量不可互换**：**用存量渗透率算本期新增，会把历年累计的采购都算进本期**。
> 换算：`适用客户数 = 已采用客户数 ÷ 渗透率`；`已采用客户本期贡献 = 已采用客户数 × 本期客均支出`。**客户数与金额不能在同一条式子中互相还原。**

> ⚠️ **渗透率取不到时**：**如实留空并说明**（写"未取到，因此未执行校准"），**不得拿分母不对的数字凑**——"消费者意愿调查""偏好排名份额""渠道覆盖率"**都不是渗透率**。
> ⚠️ **渗透率是行业级概念，不得跨层套用到单个环节。**

**触发条件**：行业有**明显地理集聚**时必加；**无集聚时写明"本行业无显著地理集聚"并跳过**，不要留空节。

|---|---|---|---|---|---|---|---|

**四条填写纪律**
1. **规模列口径必须统一**（或逐格标注）——混用口径等于没有这一列
2. **"国家级头衔"单列**——国家现代农业产业园／优势特色产业集群／骨干冷链物流基地等是**政策资源**
3. **"升级方向"是关键列**——比"它有多大"更有判断价值
4. **表下写 2–3 条横向结论**——只给表不给结论等于把分析推给读者

**行业级区域分布要多答一个问题**：**行业的地理集中度是否本身就是壁垒**？
```

```markdown
**A. 行业级失效模式（M）——判断"这条链能不能按常规上下游拆"**

| 代号 | 含义 | 判别信号 | 处理方式 |
|---|---|---|---|
| **M1** | 投入端非供应链 | 上游是**自然禀赋**（土地、水源）或**生物周期**（生长、繁育、季节），不受供应商产能约束 | 仍可拆链，但把"禀赋／生长周期／资源价格周期"当**独立维度**，与环节利润并列 |
| **M2** | 产出端非竞争定价 | 价格由**监管、配额、专卖或计划**决定，不由市场竞争形成 | **不做竞争性利润池分析**，改看定价机制→成本传导→资本开支回报 |
| **M3** | （已废止） | 原指"行业内部分层"。**实测 11 个行业 100% 都需分环节**，故"分环节"已从模式降为**标准动作**，不再作为失效模式 | 见下"分环节"说明 |
| **M4** | 非线性链条形态 | 有价值流动，但**不是"上游→中游→下游"**的线性推进 | 改用对应形态：回收→**逆向链**；物流→**节点网络**；零售→**位置×选品×周转**；文旅→**流量漏斗×单店** |
| **M5** | 尚未成链 | 技术处于实验室/中试，**没有量产环节，也没有供应商体系** | 不做产业链，改拆**创新链**：基础研究→专利→中试→首台套→客户验证→（尚未发生的）量产 |

**B. 结构性特征（S）——与 M 并列，可独立叠加的行业内部结构事实**

| 代号 | 含义 | 判别信号 | 分析要求 |
|---|---|---|---|
| **S1** | 双链并行 | 同时存在**两条逻辑不同的链**：研发/成果链 + 生产/制造链 | **两条链分别拆、分别给结论**，不可用一条链的结论覆盖另一条 |
| **S2** | 认证／许可主导 | 竞争节奏由**认证周期与准入门槛**决定，而非产能或成本 | 分析轴换成：认证周期长短 → 谁先拿到 → 护城河宽度 |
| **S3** | 长建设周期 | 从投资到投产 **≥3 年** | 回报须按**全周期折现**，用在建工程替代当期毛利率 |
| **S4** | 极度碎片化 | 企业数以万计、CR10 极低、无规模效应 | 不追"份额"，改看**出清信号**；集中度提升过程本身才是投资主题 |

**C. 本报告反复使用的判断术语**

| 术语 | 含义 | 为什么关键 |
|---|---|---|
| **分环节（标准动作）** | 产业链分析本来就**必须按环节做**——不是可选步骤 | 实测 **11 个行业 100% 都存在显著分环节差异** |
| **出清机制（五问）** | ①并购整合 ②标准与等级 ③监管门槛抬升 ④渠道集中 ⑤规模经济显著。**逐环节打分** | **≥3 条＝有出清机制；1–2 条＝出清缓慢；0 条＝碎片化陷阱** |
| **碎片化陷阱** | **长期低水平均衡**：规模不再增长、格局又无法收敛 | **比衰退更糟**——衰退会出清，陷阱不会。**投资含义是"绕开"，不是"等抄底"** |
| **投资含义矩阵** | **阶段 × 出清机制** 的交叉表 | 两行业可同判"成熟期"但投资含义相反 |
```

> ⚠️ **只写本报告实际用到的代号**——**没用到的代号删掉**，不要照搬全表（M3 已废止，只在解释"为什么不用 M3"时才写）。
> ⚠️ **权威定义在 `references/产业链与出清机制.md`**——本模块是它的**读者对照版**，不是第二份权威。

## 模块三：参数登记表（**凡参与计算或判断的输入量都要登记**）

> **触发条件**：报告中有**任何测算或推算**（市场规模、份额、单店模型、单位经济、量价拆分、TAM/SAM/SOM）时**必填**。

**参数性质六分类**

| 参数性质 | 含义 | 判断类型 |
|---|---|---|
| **观测** | 材料直接给出的原始值 | `[事实]` |
| **换算** | 原始值经单位、价格、汇率、时间或统计转换 | `[计算]` |
| **估计** | 有材料支撑、但需研究者判断的推算 | `[推断]` |
| **代理** | 目标参数缺失时的可解释替代量 | `[情境]` |
| **假设** | 为情景或预测明确设置的研究条件 | `[情境]` |
| **待核实** | 缺失或冲突输入，**不作确定核心参数** | `[待核实]` |

**登记表（每个输入量一行，含减项与系数）**

| 参数 | 数值/区间 | 单位 | 地域 | 数据所属期 | 定义/分母 | 参数性质 | 判断类型 | 材料状态 | 来源定位 | 来源原值→必要换算→模型参数 | 不确定性/替换计划 |
|---|---|---|---|---|---|---|---|---|---|---|---|

> ⚠️ **减项（出口、库存变化）与系数（占比、更换率、执行率、类比调整系数）同样是输入量，必须单独成行。**
> ⚠️ **不得只列机构名称**——必须留出可复算的换算链。
> ⚠️ **本轮计算结果不得反过来充当本轮输入证据。**

**结果精度**

| 情形 | 表达方式 |
|---|---|
| 链条最弱参数是观测/换算 | 按该参数精度给结果 |
| 关键比例是**估计值** | **两位有效数字或区间**，不制造伪精度 |
| 关键参数是代理/假设 | **必须给区间或情景**，不得给单点确定值 |

> **有效位数不超过链条上最弱的那个参数**；中间计算用未取整值，**展示值与计算值分开**。

**情景与敏感性（关键假设足以改变结果时必做）**

| 情景 | 触发条件 | 关键参数取值 | 结果 |
|---|---|---|---|
| 保守 | | | |
| 基准 | | | |
| 乐观 | | | |

**须点名 1–3 个最影响结果且最不确定的参数**，说明：变化范围 → 结果变化范围 → **哪个阈值会改变结论**。

## 3.3 过程性标注禁写（6 类）

| # | 禁写 | 改为 |
|---|---|---|
| 1 | `（应纳入，但有两处边界）` | 删掉；把边界写成正文事实 |
| 2 | `（必须声明）` | 删掉——声明就直接声明 |
| 3 | `（按 2.3.1 判据：…）`／`（见第 X 节）` | 删掉——读者不需要规则编号 |
| 4 | `（缺一即不合格）`／`（条件节）` | 删掉——那是**填写要求**，不是报告内容 |
| 5 | `（逐环节）`等自述 | 能看懂就删 |
| 6 | `（推断）`单挂段末 | ⚠️ **保留但须规范**——融入表述或放入表格"类型"列，**不散落** |

> **判据**：**括号里的内容如果换成"任何读者都不需要知道"，就删。**
>
> ⚠️ **两处合法用法不算过程性标注**：
> 1. **元信息字段内容**里的"（本报告…）"——如 `特别关注点：未指定（本报告默认关注投资可投性）`；元信息本就是在描述报告自身。
> 2. **正文声明报告口径**时的"（本报告采用 X 口径）"——这是读者需要的。
>
> **区分点**：讲"**报告是什么／采用什么口径**"＝合法；讲"**我怎么处理、改了什么、按哪条规则**"＝禁写。
